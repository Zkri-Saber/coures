کردت! بەرنامەی گەشەپێدەری باکئێند بە پایتۆنت تەواو کرد. ساتێک بوەستە و سەیری ئەوە بکە چەندە پێشکەوتوویت.

## ئێستا چی دەتوانیت بکەیت

- **دیزاینکردنی مۆدێلی داتای پەیوەندیدار** و پرسیارکردن لێیان بە SQL و SQLAlchemy
- **پەرەپێدانی بنکەدراوەیەک بە سەلامەتی** بە کۆچکردن (migrations)، تەنانەت کاتێک پێشتر داتای تێدایە
- **دروستکردنی بەرنامەی وێب کە پشت بە بنکەدراوە دەبەستێت** لەگەڵ دروستکردن، خوێندنەوە، نوێکردنەوە و سڕینەوەی تەواو
- **دیزاینکردن، دروستکردن، تاقیکردنەوە و بەڵگەنامەکردنی REST API** بە Flask
- **سەلامەتکردنی API ـەکان** بە ناسینەوەی تۆکن، مۆڵەتی سەر بە ڕۆڵ و مامەڵەی سەلامەت لەگەڵ وشەی نهێنی
- **وەک هێرشبەرێک بیر بکەیتەوە** و بەرگری لە باوترین مەترسییەکانی ئاسایشی وێب بکەیت

و **سێ پرۆژەی پۆرتفۆلیۆ**ت لەسەر GitHub هەیە بۆ سەلماندنی.

## پۆرتفۆلیۆکەت بدرەوشێنەوە

- سێ پرۆژەکەت لەسەر پرۆفایلی GitHub ـەکەت بچەسپێنە (pin).
- دڵنیابە کە هەر README ـێک ڕوون دەکاتەوە پرۆژەکە چی دەکات، چۆن جێبەجێ دەکرێت، و چیت فێر بوو.
- لە شوێنی گونجاودا تۆمارێکی کورتی شاشە یان وێنەی شاشە زیاد بکە.
- ئامادە بە بۆ قسەکردن دەربارەی یەک پرۆژە بە وردی: مۆدێلی داتا، هەڵەیەکی قورس کە چاکت کرد، و بڕیارێکی ئاسایش کە داتدا.

## دواتر بۆ کوێ بچیت

یەک بوار هەڵبژێرە و قووڵتر بڕۆ:

| هەنگاوی داهاتوو | بۆچی |
| --- | --- |
| **بڵاوکردنەوەی پرۆژەیەک** | یەکێک لە بەرنامەکانت لەسەر خانەخوێیەکی هەوری (cloud) جێبەجێ بکە لەگەڵ بنکەدراوەیەکی PostgreSQL ـی بەڕێوەبراو، کە Gunicorn لەناو کۆنتەینەرێکی Docker دا پێشکەشی دەکات، و نهێنییەکان لە گۆڕاوەکانی ژینگەدان |
| **خۆکارکردن بە CI** | GitHub Actions بەکاربهێنە بۆ جێبەجێکردنی تاقیکردنەوەکانت لە هەموو push ـێکدا |
| **FastAPI** | چوارچێوەیەکی نوێی پایتۆن بۆ API لەگەڵ پشتڕاستکردنەوە و بەڵگەنامەی خۆکار |
| **کاش و کاری پاشبنەما** | Redis بۆ کاش، و ڕیزی ئەرکەکان بۆ کاری هێواش وەک ناردنی ئیمەیڵ |
| **SQL ـی پێشکەوتوو** | ئیندێکس، پلانی پرسیار و مامەڵەکان (transactions)، بۆ ئەوەی بەرنامەکانت لە قەبارەی گەورەدا خێرا بن |
