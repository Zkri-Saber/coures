نزیکەی هەموو بەرنامەیەکی وێبی بەسوود داتا هەڵدەگرێت: بەکارهێنەران، پۆستەکان، داواکاریی کڕین، نامەکان، حیجزەکان. لەم کۆرسەدا فێر دەبیت چۆن لە بنەڕەتەوە **بەرنامەیەکی وێب بە پشتبەستن بە بنکەدراوە** دروست بکەیت.

## ئەو ستاکەی (stack) کاری لەگەڵ دەکەیت

```text
 Browser  ──HTTP──▶  Flask app  ──Python objects──▶  SQLAlchemy  ──SQL──▶  PostgreSQL
 (HTML,     ◀─────   (routes,    ◀────────────────   (ORM)        ◀─────   (database)
  JS)                 views)
```

- **PostgreSQL** داتاکان لە خشتەکاندا هەڵدەگرێت.
- **SQLAlchemy** ڕێگەت پێ دەدات وەک ئۆبجێکتی پایتۆن کار لەگەڵ ئەو داتایانەدا بکەیت لە جیاتی نووسینی SQL ـی خاو بۆ هەموو شتێک.
- **Flask** داواکارییەکان لە وێبگەڕەوە وەردەگرێت، SQLAlchemy بەکاردەهێنێت بۆ خوێندنەوە یان گۆڕینی داتا، و وەڵامێک دەنێرێتەوە.

## چی فێر دەبیت

لە کۆتایی ئەم کۆرسەدا دەتوانیت:

- لە پایتۆنەوە پەیوەندی بە بنکەدراوەیەکەوە بکەیت و SQL بە سەلامەتی جێبەجێ بکەیت
- داتاکانت وەک **مۆدێل** پێناسە بکەیت، لەگەڵ **پەیوەندییەکانی** نێوانیان
- کردارەکانی **CRUD** جێبەجێ بکەیت، واتە دروستکردن (Create)، خوێندنەوە (Read)، نوێکردنەوە (Update) و سڕینەوە (Delete)، لە هەردوو بنکەدراوە و بەرنامەی وێبدا
- بە **مایگرەیشن** ڕێکخستنی بنکەدراوەکەت بە درێژایی کات بگۆڕیت
- بیر لە بنەماکانی **مۆدێلکردنی داتای** باش بکەیتەوە: پێویستت بە چ خشتەیەکە، و چۆن بە یەکەوە دەبەسترێن

Q: لەم ستاکەدا، کاری SQLAlchemy چییە؟
- [ ] هەڵگرتنی داتاکان لەسەر دیسک
- [x] ڕێگەدان بە کۆدی پایتۆنەکەت کە وەک ئۆبجێکت کار لەگەڵ داتای بنکەدراوەدا بکات

- [ ] Connect، Run، Upload، Download
- [ ] Code، Review، Upgrade، Deploy
Why: ئەم چوار کردارە نزیکەی هەموو ئەو شتانە دەگرنەوە کە بەرنامەیەک لەگەڵ داتای هەڵگیراودا دەیکات.
