تۆ دەست بە گەشتێکی سەخت بەڵام بەبەرهەم دەکەیت. هەموو گەشەپێدەرێک، لە هەموو ئاستێکدا، چەند جار لە ڕۆژێکدا گیر دەخوات. ئەوەی گەشەپێدەرانی باش جیا دەکاتەوە ئەوە نییە کە هەرگیز گیر ناخۆن، بەڵکو ئەوەیە کە دەزانن **چۆن لە گیرخواردن دەربچن**.

## هەنگاوی 1: پەیامی هەڵەکە بخوێنەوە

پەیامەکانی هەڵەی پایتۆن ترسناک دەردەکەون، بەڵام هەوڵی یارمەتیدان دەدەن. **traceback** لە **خوارەوە بۆ سەرەوە** بخوێنەوە:

```text
Traceback (most recent call last):
  File "/home/sara/todo/app.py", line 24, in create_todo
    todo = Todo(descripton=data["description"])
TypeError: 'descripton' is an invalid keyword argument for Todo
```

- **دوا دێڕ** دەڵێت چی هەڵە بووە: ئارگومێنتێکی هەڵە نووسراو، `descripton`.
- دێڕی سەرووی پیشان دەدات **لە کوێ**: `app.py`، دێڕی 24.

زۆربەی هەڵەکان هەڵەی نووسینن، import ـێکی ونن، یان بەهایەکن کە ئەوە نین کە چاوەڕێت دەکرد.

## هەنگاوی 2: لێکۆڵینەوە

- **دووبارەی بکەرەوە.** دەتوانیت بە ئەنقەست هەڵەکە دووبارە دروست بکەیتەوە؟
- **شتەکان پیشان بدە.** `print(data)` یان `app.logger.info(data)` زیاد بکە تا ببینیت گۆڕاوێک بەڕاستی چی تێدایە.
- **کێشەکە بچووک بکەرەوە.** کۆد بکە بە لێدوان تا هەڵەکە نامێنێت. دوا شت کە لات برد گومانلێکراوەکەیە.
- **بە دەنگی بەرز ڕوونی بکەرەوە** بۆ هاوڕێیەک، یان تەنانەت بۆ مراوییەکی لاستیکی. وەسفکردنی ئەوەی *دەبێت* ڕووبدات، دێڕ بە دێڕ، زۆرجار هەڵەکە ئاشکرا دەکات.
- **پشوو بدە.** پیاسەیەکی دە خولەکی ژمارەیەکی سەرسوڕهێنەر لە هەڵەکان چارەسەر دەکات.

## هەنگاوی 3: بە کاریگەری بگەڕێ

بەدوای **خودی پەیامی هەڵەکەدا** بگەڕێ، بەبێ ئەو بەشانەی تایبەتن بە تۆ (ناوی فایل، ناوی گۆڕاو):

```text
sqlalchemy "is an invalid keyword argument"
```

سەرەتا متمانە بەم سەرچاوانە بکە:

- بەڵگەنامە فەرمییەکانی [Flask](https://flask.palletsprojects.com)، [SQLAlchemy](https://docs.sqlalchemy.org) و [PostgreSQL](https://www.postgresql.org/docs/)
- وەڵامەکانی Stack Overflow کە بەروارێکی نوێ و دەنگی زۆریان هەیە
- issue ـەکانی GitHub ـی پڕۆژەکە، بۆ هەڵەکانی خودی کتێبخانەکە

**وەشانەکە** بپشکنە: وەڵامێک کە بۆ Flask 1 یان SQLAlchemy 1.3 نووسرابێت لەوانەیە لەگەڵ وەشانەکانی ئەمڕۆدا کار نەکات.

بەڵگەنامە فەرمییەکان زۆربەیان بە ئینگلیزین. ئامرازەکانی وەرگێڕانی وێبگەڕ دەتوانن یارمەتیت بدەن، بەڵام ناوی فەنکشن و پەیامی هەڵەکان هەمیشە بە ئینگلیزی بهێڵەرەوە کاتێک دەگەڕێیت.

## هەنگاوی 4: پرسیارێکی باش بکە

ئەگەر 30 تا 45 خولەکت بەسەر بردووە و هێشتا گیرت خواردووە، لە مامۆستاکەت یان هاوپۆلەکانت بپرسە. پرسیارێکی باش وەڵامێکی خێرا وەردەگرێت. ئەمانەی تێدا بنووسە:

1. **چی هەوڵ دەدەیت بیکەیت:** "هەوڵ دەدەم کارێکی نوێ پاشەکەوت بکەم."
2. **چی ڕوویدا:** هەموو پەیامی هەڵەکە، وەک دەق، نەک وێنەیەک لە شاشەکەت.
3. **کۆدە پەیوەندیدارەکە**، هەتا بتوانیت بچووکی بکەرەوە.
4. **ئەوەی پێشتر تاقیت کردووەتەوە:** "ڕێنووسی ناوی ستوونەکانم پشکنی و `data` م پیشان دا."

## بەکارهێنانی یاریدەدەرەکانی AI

ئامرازەکانی AI دەتوانن بە باشی هەڵە و چەمکەکان ڕوون بکەنەوە. وەک مامۆستایەکی تایبەت بەکاریان بهێنە، نەک کەسێک کە لە جیاتی تۆ بنووسێت:

- بپرسە "*بۆچی* ئەمە ڕوودەدات؟" نەک "کۆدەکەم چاک بکە".
- بپشکنە کە وەڵامەکە لەگەڵ ئەو وەشانانەی بەکاریان دەهێنیت دەگونجێت.
- **پڕۆژەکانی کە دەینێریت دەبێت کاری خۆت بن.** دەبێت بتوانیت هەموو دێڕێک کە دەینێریت ڕوون بکەیتەوە.
