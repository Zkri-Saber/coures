هەموو بانگکردنێکی API **داواکارییەکی HTTP** ـە کە **وەڵامێکی HTTP** بەدوایدا دێت. تێگەیشتنی وردیان ئەوەیە کە مەزەندەکردن لە دۆزینەوەی هەڵە جیا دەکاتەوە.

## پێکهاتەی داواکارییەک

```text
POST /api/books HTTP/1.1                    ← method, path, version
Host: 127.0.0.1:5000                        ← headers
Content-Type: application/json
Authorization: Bearer eyJhbGciOi...

{"title": "Emma", "author": "Jane Austen"}  ← body (optional)
```

- **ڕێگا** (method): چی دەتەوێت بکەیت
- **ڕێڕەو** (path): کام سەرچاوە، لەگەڵ **query string** ـێکی دڵخواز وەک `?page=2`
- **سەرپەڕەکان** (headers): زانیاریی زیادە، وەک شێوەی ناوەڕۆک یان زانیاریی چوونەژوورەوەت
- **ناوەڕۆک** (body): ئەو داتایەی دەینێریت، زۆرجار JSON

## ڕێگاکانی HTTP

| ڕێگا | بەکاری بهێنە بۆ | ناوەڕۆکی هەیە؟ |
| --- | --- | --- |
| `GET` | خوێندنەوەی سەرچاوەیەک یان لیستێک | نەخێر |
| `POST` | دروستکردنی سەرچاوەیەکی نوێ، یان ئەنجامدانی کردارێکی وەک گەڕان | بەڵێ |
| `PUT` | جێگرتنەوەی تەواوی سەرچاوەیەک | بەڵێ |
| `PATCH` | گۆڕینی بەشێک لە سەرچاوەیەک | بەڵێ |
| `DELETE` | لابردنی سەرچاوەیەک | زۆرجار نەخێر |

داواکارییەکانی `GET` هەرگیز نابێت داتا بگۆڕن. وێبگەڕ، کاش و بزوێنەرەکانی گەڕان وا دادەنێن کە دووبارەکردنەوەیان سەلامەتە.

## پێکهاتەی وەڵامێک

```text
HTTP/1.1 201 CREATED                        ← status code
Content-Type: application/json              ← headers

{"success": true, "created": 3}             ← body
```

## کۆدەکانی دۆخ

یەکەم ژمارە جۆرەکەت پێ دەڵێت: **2xx** سەرکەوتن، **4xx** ڕاژەخوازەکە هەڵەی کردووە، **5xx** ڕاژەکار شکستی هێناوە.

| کۆد | مانا | کەی بەکاری بهێنیت |
| --- | --- | --- |
| `200 OK` | سەرکەوتن | زۆربەی داواکارییە سەرکەوتووەکان |
| `201 Created` | سەرچاوەیەکی نوێ دروست کرا | دوای `POST` ـێکی سەرکەوتوو |
| `204 No Content` | سەرکەوتن، هیچ شتێک بۆ گەڕاندنەوە نییە | هەندێک جار دوای `DELETE` |
| `400 Bad Request` | داواکارییەکە شێواوە یان داتای ونە | خانە پێویستەکان ونن |
| `401 Unauthorized` | نەچووەتە ژوورەوە، یان زانیاریی چوونەژوورەوە نادروستە | تۆکنی ون یان خراپ (بەشی 4) |
| `403 Forbidden` | چووەتە ژوورەوە، بەڵام ڕێگەپێنەدراوە | مۆڵەتی ون (بەشی 4) |
| `404 Not Found` | سەرچاوەکە بوونی نییە | ID یان URL ـی نەناسراو |
| `405 Method Not Allowed` | URL ـەکە هەیە بەڵام بۆ ئەم ڕێگایە نا | `PUT` لەسەر ڕێڕەوێکی تەنها-`GET` |
| `422 Unprocessable` | شێوەی دروستە، بەڵام ناتوانرێت مامەڵەی لەگەڵ بکرێت | JSON ـی دروست کە یاسایەک دەشکێنێت |
| `500 Internal Server Error` | شتێک لەسەر ڕاژەکار تێکچوو | هەڵەی چاوەڕواننەکراو |

## یەکەم API ـی Flask ـت

فۆڵدەرێکی نوێ و ژینگەیەکی مەجازی دروست بکە (وەک لە وانەی ئامادەکردندا)، پاشان Flask دابمەزرێنە و `app.py` دروست بکە:

```python
from flask import Flask, jsonify, request

app = Flask(__name__)


@app.get("/api/hello")
def hello():
    name = request.args.get("name", "world")
    return jsonify(message=f"Hello, {name}!")


@app.post("/api/echo")
def echo():
    data = request.get_json(silent=True)
    if data is None:
        return jsonify(error="Send JSON with Content-Type: application/json"), 400
    return jsonify(you_sent=data), 201
```

- `@app.get` و `@app.post` فەنکشنێک بۆ URL و ڕێگایەک تۆمار دەکەن.
- `jsonify()` داتای پایتۆن دەکات بە وەڵامێکی JSON لەگەڵ سەرپەڕەی `Content-Type` ـی دروست.
- `request.args` ـی query string هەڵدەگرێت؛ `request.get_json()` ناوەڕۆکێکی JSON دەخوێنێتەوە.
- گەڕاندنەوەی tuple ـێک، `(response, 201)`، کۆدی دۆخەکە دیاری دەکات.

جێبەجێی بکە:

```bash
flask --app app run --debug
```

## تاقیکردنەوەی خاڵەکانی کۆتایی بە curl

`curl` لە تێرمیناڵەوە داواکاریی HTTP دەنێرێت. لەناو ماک، لینوکس و ویندۆز 10 و دواتردا هەیە. لە کاتێکدا Flask کار دەکات، تێرمیناڵێکی **دووەم** بکەرەوە:

```bash
curl http://127.0.0.1:5000/api/hello
curl "http://127.0.0.1:5000/api/hello?name=Sara"

curl -X POST http://127.0.0.1:5000/api/echo \
  -H "Content-Type: application/json" \
  -d '{"course": "backend"}'

curl -i http://127.0.0.1:5000/api/nothing-here
```

| ئاڵا | مانا |
| --- | --- |
| `-X POST` | ئەم ڕێگایە بەکاربهێنە |
| `-H "..."` | سەرپەڕەیەک زیاد بکە |
| `-d '...'` | ئەم ناوەڕۆکە بنێرە |
| `-i` | دێڕی دۆخ و سەرپەڕەکانیش پیشان بدە |

> لەسەر Windows PowerShell، `curl.exe` بەکاربهێنە و JSON لەناو نیشانەی وتەی دووانەدا دابنێ لەگەڵ نیشانەی وتەی ناوەوەی پارێزراو، یان ئامرازێکی گرافیکی وەک [Postman](https://www.postman.com) یان [Bruno](https://www.usebruno.com) بەکاربهێنە.

## ڕێگەدان بە وێبگەڕەکان لە ماڵپەڕەکانی ترەوە: CORS

ئەگەر فرۆنتئێندێک لە `http://localhost:3000` API ـەکەت لە `http://127.0.0.1:5000` بانگ بکات، وێبگەڕەکە بە شێوەی بنەڕەتی بلۆکی دەکات. ئەم **سیاسەتی هەمان-سەرچاوەیە** (same-origin policy) بەکارهێنەران دەپارێزێت. **CORS** (Cross-Origin Resource Sharing) ئەو ڕێگایەیە کە API ـەکەت بە وێبگەڕ دەڵێت کام سەرچاوەکانی تر دەتوانن بانگی بکەن.

```bash
pip install flask-cors
```

```python
from flask_cors import CORS

CORS(app, resources={r"/api/*": {"origins": "http://localhost:3000"}})
```

تەنها ئەو سەرچاوانە لیست بکە کە بەڕاستی پێویستیان بە دەستگەیشتنە. `"*"` (هەر ماڵپەڕێک) بۆ API ـێکی گشتیی تەنها-خوێندنەوە کێشە نییە، بەڵام بۆ یەکێک کە چوونەژوورەوە بەکاردەهێنێت نا.

:::quiz
Q: ڕاژەخوازێک داواکارییەکی دروست دەنێرێت بۆ دروستکردنی کتێبێک، و پاشەکەوت دەکرێت. کام کۆدی دۆخ گونجاوترە؟
- [ ] 200
- [x] 201
- [ ] 204
Why: 201 Created بە ڕاژەخواز دەڵێت سەرچاوەیەکی نوێ ئێستا بوونی هەیە.

Q: کام کۆدی دۆخ واتە "چوویتە ژوورەوە، بەڵام ڕێگەت پێ نەدراوە ئەمە بکەیت"؟
- [ ] 401
- [x] 403
- [ ] 404
Why: 401 واتە نەناسراوەتەوە (not authenticated). 403 واتە ناسراوەتەوە بەڵام ڕێگەپێنەدراوە (not authorized).

Q: CORS چی کۆنترۆڵ دەکات؟
- [ ] API ـەکەت دەتوانێت پەیوەندی بە کام بنکەدراوانەوە بکات
- [x] JavaScript ـی کام ماڵپەڕەکانی تر ڕێگەیان پێ دەدرێت لە وێبگەڕێکەوە API ـەکەت بانگ بکەن
- [ ] API ـەکەت چەند خێرا وەڵام دەداتەوە
Why: سەرپەڕەکانی CORS بە وێبگەڕەکان دەڵێن ئایا پەڕەکانی سەرچاوەیەکی تر دەتوانن وەڵامەکانی API ـەکەت بخوێننەوە.
:::
