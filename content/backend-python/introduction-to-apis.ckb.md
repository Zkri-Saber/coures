لە بەشی 2 دا، بەرنامە Flask ـەکەت پەڕەی HTML ـی دەنارد بۆ وێبگەڕێک. بەڵام ئەمڕۆ، هەمان باکئێند زۆرجار لە یەک کاتدا خزمەتی ماڵپەڕێک، بەرنامەیەکی مۆبایل، و نەرمەکاڵای کۆمپانیاکانی تر دەکات. هەموویان لە ڕێگەی **API** ـەوە قسەی لەگەڵ دەکەن.

## API چییە؟

**API** (Application Programming Interface) ڕێگایەکی دیاریکراوە کە پارچە نەرمەکاڵایەک داوای داتا یان کردار لە یەکێکی تر بکات، بەبێ ئەوەی پێویست بێت بزانێت لە ناوەوە چۆن کار دەکات.

چێشتخانەیەک بهێنە بەرچاوت. تۆ (**ڕاژەخواز**) ناچیتە ناو چێشتخانەکەوە (**ڕاژەکار**). داواکارییەکەت دەدەیت بە گارسۆنێک (**API**)، کە یاسایەکی ڕوون پەیڕەو دەکات دەربارەی ئەوەی چی و چۆن دەتوانیت داوا بکەیت، پاشان خواردنەکەت (**وەڵام**) بۆ دەهێنێتەوە.

هەمیشە API بەکاردەهێنیت بەبێ ئەوەی هەستی پێ بکەیت:

- بەرنامەیەکی کەشوهەوا داوای پێشبینی لە API ـی خزمەتگوزارییەکی کەشوهەوا دەکات.
- دوگمەی "چوونەژوورەوە بە Google" API ـی ناسنامەی Google بەکاردەهێنێت.
- پارەدان لە فرۆشگایەکی ئۆنلاین API ـی دابینکەرێکی پارەدان بانگ دەکات.
- ئەو بەرنامەی لیستی کارانەی تازە دروستت کرد: بانگکردنەکانی `fetch` لە JavaScript ـەکەتدا پێشتر داواکاریی API بوون.

## بۆچی API گرنگە

- **یەک باکئێند، زۆر فرۆنتئێند.** هەمان API دەتوانێت ماڵپەڕێک، بەرنامەیەکی iPhone و بەرنامەیەکی ئەندرۆید کار پێ بکات.
- **جیاکردنەوە.** تیمەکانی فرۆنتئێند و باکئێند دەتوانن سەربەخۆ کار بکەن، تا ئەو کاتەی لەسەر API ـەکە ڕێککەوتوون.
- **شاردنەوەی ئاڵۆزی.** ڕاژەخوازەکان پێویست ناکات دەربارەی بنکەدراوە یان کۆدەکەت بزانن؛ تەنها API دەبینن.
- **دەستگەیشتنی کۆنترۆڵکراو.** API بڕیار دەدات هەر ڕاژەخوازێک چی دەتوانێت ببینێت و بیکات (بەشی 4 تەواوی دەربارەی ئەمەیە).

## ئینتەرنێت چۆن داواکارییەکانی API دەگوازێتەوە

API ـەکان لەسەر وێب بە چەند چینێک لە **پرۆتۆکۆل** دا دەڕۆن، کە یاسای ڕێککەوتوون بۆ پەیوەندیکردن:

| چین | پرۆتۆکۆل | کار |
| --- | --- | --- |
| بەرنامە | **HTTP** (یان HTTPS) | شێوەی داواکاری و وەڵامەکان: ڕێگاکان، URL، سەرپەڕەکان (headers)، کۆدی دۆخ |
| ئاسایش | **TLS** | پەیوەندییەکە شێوەگۆڕ (encrypt) دەکات. HTTPS بریتییە لە HTTP لەسەر TLS |
| گواستنەوە | **TCP** | داتا بە متمانەوە و بە ڕیز دەگەیەنێت |
| ئینتەرنێت | **IP** | ناونیشان دەدات و پاکێتەکان لە نێوان کۆمپیوتەرەکاندا ئاراستە دەکات |

وەک گەشەپێدەرێکی باکئێند، زۆرجار لە چینی HTTP دا کار دەکەیت. Flask ئەوانی تری بۆ تۆ دەکات.

## REST

**REST** (Representational State Transfer) شێوازێکە بۆ دیزاینکردنی API ـی وێب. API ـێک کە پەیڕەوی بکات پێی دەوترێت **RESTful**. بیرۆکە سەرەکییەکانی:

1. **ڕاژەخواز-ڕاژەکار:** ڕاژەخواز و ڕاژەکار جیان و دەتوانن سەربەخۆ بگۆڕێن.
2. **بێ-دۆخ (stateless):** هەر داواکارییەک هەموو ئەو شتانەی تێدایە کە ڕاژەکار بۆ مامەڵەکردن لەگەڵیدا پێویستییەتی. ڕاژەکار داواکارییە پێشووەکان لەبیر ناهێڵێتەوە.
3. **سەرچاوەکان بە URL:** هەموو شتێک **سەرچاوەیەکە** (resource) (کتێبێک، بەکارهێنەرێک، داواکارییەکی کڕین) بە ناونیشانی تایبەت بە خۆیەوە، وەک `/api/books/7`.
4. **ڕووکارێکی یەکگرتوو:** ڕێگا ستانداردەکانی HTTP بەکاردەهێنیت بۆ کارکردن لەسەر سەرچاوەکان: `GET` بۆ خوێندنەوە، `POST` بۆ دروستکردن، `PATCH` یان `PUT` بۆ نوێکردنەوە، `DELETE` بۆ لابردن.
5. **کاشکراو (cacheable):** وەڵامەکان دەڵێن ئایا دەکرێت کاش بکرێن، بۆ پاشەکەوتکردنی کاری دووبارە.
6. **چینچین:** ڕاژەخوازەکان پێویست ناکات بزانن ئایا لەگەڵ ڕاژەکارە ڕاستەقینەکەدا قسە دەکەن یان لەگەڵ proxy، دابەشکەری بار (load balancer) یان کاشێک لە نێوانیاندا.

## JSON: زمانی API ـەکان

زۆربەی API نوێیەکان داتا وەک **JSON** (JavaScript Object Notation) دەنێرن، شێوەیەکی دەقی سادە کە نزیکەی هەموو زمانێکی پرۆگرامسازی دەتوانێت بیخوێنێتەوە:

```json
{
  "success": true,
  "book": {
    "id": 7,
    "title": "The Hobbit",
    "author": "J. R. R. Tolkien",
    "rating": 5
  }
}
```

نزیکەی ڕێک وەک dictionary ـێکی پایتۆن دەردەکەوێت، و Flask لە نێوان هەردووکیاندا بۆت دەگۆڕێت.
