مۆدێلی داتاکەت لە ماوەی پڕۆژەیەکدا زۆر جار دەگۆڕێت: ستوونی نوێ، خشتەی نوێ، ناوی گۆڕاو. بەڵام `db.create_all()` ناتوانێت خشتە هەبووەکان بگۆڕێت، و سڕینەوەی خشتەکان داتای ڕاستەقینە لەناو دەبات. **مایگرەیشن** (migration) ئەمە چارەسەر دەکات.

## مایگرەیشن چییە؟

مایگرەیشن فایلێکی بچووکی پایتۆنە کە **یەک گۆڕانکاری** لە ڕێکخستنی (schema) بنکەدراوەدا وەسف دەکات، بە دوو فەنکشن:

- `upgrade()` گۆڕانکارییەکە جێبەجێ دەکات
- `downgrade()` هەڵیدەوەشێنێتەوە

مایگرەیشنەکان لە پڕۆژەکەتدا هەڵدەگیرێن و commit دەکرێن بۆ Git، بۆیە ڕێکخستنی بنکەدراوە **کۆنترۆڵی وەشانی** هەیە هەروەک کۆدەکەت. هەموو کەسێک لە تیمەکەدا، و ڕاژەکاری بەرهەمهێنانت (production)، دەتوانن هەمان گۆڕانکارییەکان بە هەمان ڕیز جێبەجێ بکەن.

**Alembic** ئامرازی مایگرەیشنی SQLAlchemy ـە، و **Flask-Migrate** بە هێڵی فەرمانی Flask ـەوە دەیبەستێتەوە. پێشتر `migrate = Migrate(app, db)` ـت بۆ `app.py` زیاد کرد.

## ڕێڕەوی کار

```bash
flask --app app db init                       # once per project: creates the migrations/ folder
flask --app app db migrate -m "create todos table"   # generate a migration from your models
flask --app app db upgrade                    # apply it to the database
```

ئەگەر لە وانەی پێشوودا خشتەی `todos` ـت بە `create_all()` دروست کرد، سەرەتا لە `psql` دا بیسڕەوە (`DROP TABLE todos;`) تا مایگرەیشنەکان لە سەرەتاوە بەڕێوەی ببەن.

هەر جارێک دوای ئەوە مۆدێلەکانت دەگۆڕیت:

1. مۆدێلەکە لە `app.py` دا دەستکاری بکە
2. `flask --app app db migrate -m "describe the change"`
3. **فایلە نوێیەکە لە `migrations/versions/` دا بکەرەوە و بیخوێنەوە**
4. `flask --app app db upgrade`
5. فایلی مایگرەیشنەکە commit بکە بۆ Git

فەرمانە بەسوودەکانی تر:

| فەرمان | چی دەکات |
| --- | --- |
| `flask --app app db downgrade` | هەڵوەشاندنەوەی نوێترین مایگرەیشن |
| `flask --app app db current` | پیشاندانی ئەوەی بنکەدراوەکە لەسەر کام مایگرەیشنە |
| `flask --app app db history` | لیستکردنی هەموو مایگرەیشنەکان بە ڕیز |

## نموونە: زیادکردنی ستوونێک بۆ خشتەیەک کە داتای تێدایە

با پلەی گرنگی (priority) بدەین بە کارەکان. یەک دێڕ بۆ مۆدێلەکە زیاد بکە:

```python
class Todo(db.Model):
    __tablename__ = "todos"

    id: Mapped[int] = mapped_column(primary_key=True)
    description: Mapped[str] = mapped_column(String(200))
    completed: Mapped[bool] = mapped_column(default=False)
    priority: Mapped[int] = mapped_column(default=1, server_default="1")
```

مایگرەیشنەکە دروست بکە:

```bash
flask --app app db migrate -m "add priority to todos"
```

Alembic مۆدێلەکانت لەگەڵ بنکەدراوەکەدا بەراورد دەکات و ئەمە دەنووسێت:

```python
def upgrade():
    with op.batch_alter_table('todos', schema=None) as batch_op:
        batch_op.add_column(sa.Column('priority', sa.Integer(), server_default='1', nullable=False))

def downgrade():
    with op.batch_alter_table('todos', schema=None) as batch_op:
        batch_op.drop_column('priority')
```

بۆچی `server_default="1"`؟ ستوونەکە پێویستە (`NOT NULL`)، بەڵام خشتەکە پێشتر ڕیزی تێدایە. `default=1` تەنها بۆ ئۆبجێکتە نوێیەکان کار دەکات کە لە پایتۆندا دروست دەکرێن؛ `server_default` بە **بنکەدراوەکە** دەڵێت چی بخاتە ناو ڕیزە هەبووەکانەوە. بەبێ ئەوە، upgrade ـەکە شکست دەهێنێت.

`flask --app app db upgrade` جێبەجێ بکە، پاشان لە `psql` دا بیپشکنە: هەموو کارێکی هەبوو ئێستا `priority = 1` ی هەیە.

## یاساکانی مایگرەیشنی سەلامەت

- **هەمیشە مایگرەیشنە دروستکراوەکان بخوێنەوە.** دروستکردنی خۆکار بەسوودە بەڵام تەواو نییە. بۆ نموونە ناتوانێت ستوونێکی ناوگۆڕاو بناسێتەوە: ستوونێکی سڕاو و یەکێکی نوێ دەبینێت، کە داتاکان لەناو دەبات.
- **هەرگیز مایگرەیشنێک دەستکاری مەکە کە پێشتر لەسەر بنکەدراوەیەکی هاوبەش جێبەجێ کراوە.** لە جیاتی ئەوە یەکێکی نوێ دروست بکە.
- **بیر لە ڕیزە هەبووەکان بکەرەوە** هەر کاتێک ستوونێکی پێویست زیاد دەکەیت. لە وانەی CRUD ـی داهاتوودا حاڵەتێکی ئاڵۆزتر چارەسەر دەکەیت.
- **`downgrade()` یش تاقی بکەرەوە**، تا بتوانیت لە گۆڕانکارییەکی خراپ بکشێیتەوە.
