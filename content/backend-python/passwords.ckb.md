وشەی نهێنی باوترین ڕێگای چوونەژوورەوەیە، و یەکێکە لە باوترین ڕێگاکانی شکاندنی سیستەمەکان. تەنانەت ئەگەر لە بەرهەمهێناندا (production) دابینکەرێکی ناسنامە بەکاربهێنیت، پێویستە بزانیت چۆن بە دروستی مامەڵە لەگەڵ وشەی نهێنیدا بکەیت، هەم بۆ پرۆژەکانی خۆت و هەم بۆ دۆزینەوەی کۆدی مەترسیدار لە کۆدی کەسانی تردا.

## هەرگیز وشەی نهێنی وەک خۆی هەڵمەگرە

ئەگەر بنکەدراوەکەت ڕۆژێک بدزرێتە دەرەوە (و زۆریان دەدزرێنە دەرەوە)، هەموو وشەیەکی نهێنی کە وەک دەقی ئاسایی هەڵگیرابێت دەستبەجێ ئاشکرا دەبێت. لەبەر ئەوەی خەڵک وشەی نهێنی دووبارە بەکاردەهێننەوە، ئەمە ئیمەیڵ، بانک و هەژمارە کۆمەڵایەتییەکانیشیان ئاشکرا دەکات.

**شێوەگۆڕینی** وشەی نهێنیش وەڵام نییە: هەر کەسێک کلیلەکە بدزێت دەتوانێت هەموویان بکاتەوە. لە جیاتی ئەوە، **هاشێک** (hash) هەڵبگرە.

## هاشکردن، خوێکردن و هێواشکردنەوە

**فەنکشنی هاش** وشەیەکی نهێنی دەکات بە پەنجەمۆرێک کە ناتوانرێت بگەڕێنرێتەوە. بۆ چوونەژوورەوەی کەسێک، ئەوەی نووسیویەتی هاش دەکەیت و بەراوردی دەکەیت لەگەڵ هاشە هەڵگیراوەکە.

بەڵام هاشە خێرا ئاساییەکانی وەک SHA-256 بەس نین:

- **وشەی نهێنیی وەک یەک هاشی وەک یەک دەدەن**، بۆیە یەک هاشی شکێنراو هەموو ئەوانە ئاشکرا دەکات کە `password123` ـیان بەکارهێناوە. چارەسەرەکە **خوێیە** (salt): داتای هەڕەمەکی کە پێش هاشکردن بۆ هەر وشەیەکی نهێنی زیاد دەکرێت، و لە تەنیشت هاشەکەوە هەڵدەگیرێت. ئێستا وشەی نهێنیی وەک یەک هاشی جیاوازیان هەیە.
- **هاشی خێرا دەکرێت بە خێرایی مەزەندە بکرێت.** هێرشبەران ملیاران مەزەندە لە چرکەیەکدا لەسەر کارتی گرافیک تاقی دەکەنەوە. ئەلگۆریتمەکانی هاشکردنی وشەی نهێنی بە ئەنقەست **هێواشن** و بیرگەیەکی زۆر بەکاردەهێنن، بۆ ئەوەی هەر مەزەندەیەک گران بێت.

ئەلگۆریتمێکی هاشکردنی وشەی نهێنی بەکاربهێنە کە بۆ ئەم مەبەستە دروست کرابێت: **Argon2id**، **scrypt** یان **bcrypt**.

## هاشکردنی وشەی نهێنی لە Flask دا

کتێبخانەی هاوەڵی Flask، واتە Werkzeug، یارمەتیدەری سەلامەتی تێدایە. ئەلگۆریتمی بنەڕەتیی ئێستای scrypt ـە، لەگەڵ خوێیەکی هەڕەمەکی بۆ هەر وشەیەکی نهێنی:

```python
from werkzeug.security import generate_password_hash, check_password_hash

stored = generate_password_hash("correct horse battery staple")
print(stored)
# scrypt:32768:8:1$PnKKgPIc0K8F8...$a7f3...   (algorithm, settings, salt, hash)

check_password_hash(stored, "correct horse battery staple")   # True
check_password_hash(stored, "Correct horse battery staple")   # False
```

مۆدێلێکی بەکارهێنەر لەگەڵ خۆتۆمارکردن و چوونەژوورەوە لەوانەیە بەم شێوەیە بێت:

```python
class User(db.Model):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(String(254), unique=True)
    password_hash: Mapped[str] = mapped_column(String(255))

    def set_password(self, password):
        self.password_hash = generate_password_hash(password)

    def check_password(self, password):
        return check_password_hash(self.password_hash, password)
```

```python
@app.post("/api/login")
def login():
    body = request.get_json(silent=True) or {}
    user = db.session.execute(
        db.select(User).filter_by(email=body.get("email", "").lower())
    ).scalar_one_or_none()
    if user is None or not user.check_password(body.get("password", "")):
        abort(401)          # same response either way
    ...                     # create a session or token
```

سەرنج بدە کە ئیمەیڵێکی هەڵە و وشەیەکی نهێنیی هەڵە **هەمان وەڵام** وەردەگرن. پەیامی جیاواز ("بەکارهێنەری وا نییە" بەرامبەر "وشەی نهێنی هەڵەیە") ڕێگە بە هێرشبەران دەدات بزانن کام ئیمەیڵانە هەژماریان هەیە.

## چی سیاسەتێکی باشی وشەی نهێنی دروست دەکات؟

ڕێنمایی نوێی پەیمانگای نیشتمانیی ستاندارد و تەکنەلۆژیای ئەمریکا (NIST SP 800-63B-4، 2025) ڕوونە، و جیاوازە لەو یاسایانەی لەوانەیە بینیبێتت:

- **درێژی گرنگترینە.** لانیکەم **15 پیت** داوا بکە کاتێک وشەی نهێنی تاکە هۆکارە، یان لانیکەم 8 کاتێک لەگەڵ MFA تێکەڵ کراوە.
- **ڕێگە بە وشەی نهێنیی درێژ بدە**، لانیکەم 64 پیت، لەوانە بۆشایی و هەر پیتێک. ئەمە پشتگیریی ڕستەی نهێنی (passphrase) دەکات.
- **یاسای پێکهاتە بەزۆر مەسەپێنە** وەک "یەک پیتی گەورە، یەک ژمارە، یەک هێما". وشەی نهێنی قورستر دەکەن بۆ لەبیرکردن، نەک بەهێزتر.
- **گۆڕینی ڕێکوپێکی وشەی نهێنی بەزۆر مەسەپێنە.** تەنها کاتێک گۆڕین داوا بکە کە بەڵگەی شکاندن هەبێت.
- **وشە نهێنییە نوێیەکان بەراورد بکە لەگەڵ لیستێکی ڕەش** (blocklist) لە وشە نهێنییە باوەکان و ئەوانەی پێشتر دزراون.
- **هیچ پرسیاری ئاسایش یان ئاماژەی وشەی نهێنی نەبێت.**

## پاراستنەکانی تر لە دەوری وشەی نهێنی

- **هەوڵەکانی چوونەژوورەوە سنووردار بکە** بۆ هەر هەژمار و هەر ناونیشانێکی IP، بۆ ئەوەی هێرشبەران نەتوانن ملیۆنان مەزەندە تاقی بکەنەوە. پاشکۆی Flask-Limiter دەتوانێت یارمەتی بدات.
- **MFA پێشکەش بکە**، و هانی بەکارهێنانی بەڕێوەبەری وشەی نهێنی (password manager) بدە.
- **هەرگیز وشەی نهێنی تۆمار (log) مەکە**، تەنانەت هەوڵە شکستخواردووەکانیش. تۆمارەکانی هەڵە و چاپکردنەکانی دۆزینەوەی هەڵەت بپشکنە.
- **لە هەموو شوێنێکدا HTTPS بەکاربهێنە**، بۆ ئەوەی وشەی نهێنی هەرگیز بەبێ شێوەگۆڕین نەنێردرێت.
- **تۆکنەکانی ڕێکخستنەوە** (reset tokens) دەبێت هەڕەمەکی، یەکجار-بەکارهاتوو و کورتخایەن بن. بە `secrets.token_urlsafe(32)` دروستیان بکە، هەرگیز بە `random` نا.
