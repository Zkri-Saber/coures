مۆسیقاژەنەکان پێویستیان بە شوێن هەیە بۆ ژەنین، و شوێنەکانی نمایش پێویستیان بە مۆسیقاژەن هەیە بۆ پڕکردنەوەی خشتەکانیان. لەم پڕۆژەیەدا باکئێندی **ماڵپەڕێکی حیجزکردن** دروست دەکەیت کە شوێنەکان و هونەرمەندان دەتوانن خۆیان تێدا تۆمار بکەن و پێکەوە **ئاهەنگ** (show) ڕێک بخەن.

ئەم پڕۆژەیە نیشانی دەدات کە دەتوانیت مۆدێلێکی داتای پەیوەندیدار دیزاین بکەیت، بە SQLAlchemy و مایگرەیشن دروستی بکەیت، و بە بەرنامەیەکی وێبی Flask ـی کاراوە بیبەستیتەوە.

## چی دروست دەکەیت

بەرنامەیەکی وێبی Flask لەگەڵ پەڕەی HTML (قاڵبی Jinja) کە پشت بە PostgreSQL دەبەستێت، کە بەکارهێنەران تێیدا دەتوانن:

- هەموو شوێنەکان **لیست بکەن**، بە پێی شار و پارێزگا کۆکراونەتەوە، و هەموو هونەرمەندان
- پەڕەی شوێنێک یان هونەرمەندێک **ببینن** کە وردەکارییەکانی و ئاهەنگە **داهاتوو** و **ڕابردووەکانی** پیشان دەدات، لەگەڵ ژمارەکانیان
- شوێن، هونەرمەند و ئاهەنگی نوێ لە ڕێگەی فۆڕمەکانەوە **دروست بکەن**
- بە ناو بەدوای شوێن و هونەرمەنداندا **بگەڕێن**: بەشەکی و بەبێ جیاوازیی پیتی گەورە و بچووک، بۆیە `"hop"` "The Musical **Hop**" دەدۆزێتەوە و "Park Square Live Music & Coffee" ناگونجێت
- شوێنێک و هونەرمەندێک **دەستکاری بکەن**
- شوێنێک **بسڕنەوە** (ئامانجی زیادە)

دیزاینی پەڕەکان خۆت هەڵیدەبژێریت. HTML ـی سادە و پاک تەواو کێشە نییە: ئەم پڕۆژەیە لەسەر باکئێند هەڵدەسەنگێندرێت.

## مۆدێلی داتا

پێش نووسینی کۆد بە وردی پلانی بۆ دابنێ. لانیکەم پێویستت بەمانە دەبێت:

| مۆدێل | خانە پێشنیارکراوەکان |
| --- | --- |
| **Venue** (شوێن) | ناو، شار، پارێزگا، ناونیشان، تەلەفۆن، جۆرەکانی مۆسیقا (genres)، بەستەری وێنە، بەستەری ماڵپەڕ، بەستەری فەیسبووک، بەدوای هونەرمەنددا دەگەڕێت (ڕاست/هەڵە)، وەسفی گەڕان |
| **Artist** (هونەرمەند) | ناو، شار، پارێزگا، تەلەفۆن، جۆرەکانی مۆسیقا، بەستەری وێنە، بەستەری ماڵپەڕ، بەستەری فەیسبووک، بەدوای شوێندا دەگەڕێت (ڕاست/هەڵە)، وەسفی گەڕان |
| **Show** (ئاهەنگ) | شوێن، هونەرمەند، کاتی دەستپێکردن |

ئاهەنگێک یەک هونەرمەند بە یەک شوێنەوە دەبەستێتەوە لە کاتێکی دیاریکراودا. هونەرمەندێک زۆر ئاهەنگ دەژەنێت و شوێنێک میوانداریی زۆر ئاهەنگ دەکات، بۆیە **Show** خشتەی تایبەت بە خۆیەتی بە دوو کلیلی بیانییەوە:

```text
venues ◀─── shows ───▶ artists
  1     many  │  many    1
              └─ start_time
```

بیر لەمانە بکەرەوە:

- کام خانانە **پێویستن**، و کامیان دڵخوازن؟
- چۆن **جۆرەکانی مۆسیقا** هەڵدەگریت (شوێنێک یان هونەرمەندێک دەتوانێت چەندینی هەبێت)؟ هەڵبژاردەکان بریتین لە ستوونێکی `ARRAY` ـی PostgreSQL، یان خشتەیەکی جیای `genres` لەگەڵ پەیوەندییەکی زۆر-بۆ-زۆر. هەر یەکێکیان قبوڵە ئەگەر بتوانیت هەڵبژاردنەکەت لە README دا ڕوون بکەیتەوە.
- کاتێک شوێنێک دەسڕدرێتەوە دەبێت چی بەسەر ئاهەنگەکاندا بێت؟

## مەرجەکان

| بوار | پڕۆژەکەت مەرجەکان پڕ دەکاتەوە کاتێک... |
| --- | --- |
| **مۆدێلی داتا** | مۆدێلەکان ڕێکخراون (normalized)، بە کلیلی سەرەکی و بیانیی دروست و پەیوەندییەکان، و بەبێ هۆ هیچ داتایەک لە نێوان خشتەکاندا دووبارە نابێتەوە |
| **مایگرەیشن** | ڕێکخستنی بنکەدراوە **تەنها** لە ڕێگەی مایگرەیشنەکانی Flask-Migrate ـەوە دروست دەکرێت و دەگۆڕدرێت، هەموویان commit کراون بۆ Git. هیچ `db.create_all()` ـێک لە بەرنامەکەدا نییە |
| **داتای ڕاستەقینە** | هەموو پەڕەیەک لە بنکەدراوەوە دەخوێنێتەوە و تێیدا دەنووسێت. هیچ داتای نموونەیی ڕاستەوخۆ لە view یان قاڵبەکاندا نییە |
| **دروستکردن** | شوێن، هونەرمەند و ئاهەنگی نوێ لە ڕێگەی فۆڕمەکانەوە دروست دەکرێن، بە SQLAlchemy پاشەکەوت دەکرێن، و پەیامی سەرکەوتن یان هەڵە پیشان دەدەن |
| **خوێندنەوە** | پەڕەکانی لیست و وردەکاری کار دەکەن. پەڕەکانی وردەکاری ئاهەنگە داهاتوو و ڕابردووەکان بە بەکارهێنانی کاتی ئێستا لێک جیا دەکەنەوە، لەگەڵ ژمارەکانیان |
| **گەڕان** | گەڕان بەشەکی و بەبێ جیاوازیی پیتی گەورە و بچووکە، و ژمارەی ئەنجامەکان پیشان دەدات |
| **نوێکردنەوە** | شوێنێک و هونەرمەندێک دەتوانرێن دەستکاری بکرێن، بە بەهای هەبوو کە لە فۆڕمەکەدا پڕکراونەتەوە |
| **هەڵەکان** | کاری بنکەدراوە لە try/except لەگەڵ rollback دایە. تۆمارە ونەکان پەڕەی 404 پیشان دەدەن |
| **کوالیتیی کۆد** | کۆد ڕێکخراو، یەکگرتوو و خوێندنەوەی ئاسانە، بەبێ کۆدی بەکارنەهاتوو یان نهێنیی commit کراو |
| **README** | ڕوونی دەکاتەوە پڕۆژەکە چییە، و چۆن دابمەزرێنرێت، بنکەدراوەکە دروست بکرێت، مایگرەیشنەکان جێبەجێ بکرێن و بەرنامەکە دەست پێ بکرێت |

## هەنگاوە پێشنیارکراوەکان

1. **ڕێکخستنی بنکەدراوەکەت بکێشە** لەسەر کاغەز یان تەختەیەک. لەگەڵ هاوپۆلێکدا بیپشکنە.
2. پڕۆژەکە ئامادە بکە: ژینگەی مەجازی، `requirements.txt`، `.gitignore`، بنکەدراوەیەکی PostgreSQL.
3. مۆدێلەکان بنووسە، پاشان `flask db init` و `migrate` و `upgrade`.
4. سەرەتا فۆڕمەکانی **دروستکردن** دروست بکە، تا داتات هەبێت بۆ پیشاندان.
5. پەڕەکانی لیست و وردەکاری دروست بکە. پرسیار بەکاربهێنە بۆ جیاکردنەوەی ئاهەنگە داهاتوو و ڕابردووەکان؛ لە پایتۆندا بەسەر هەموو ئاهەنگێکدا لووپ مەکە.
6. گەڕان زیاد بکە، پاشان دەستکاریکردن، پاشان سڕینەوە.
7. هەموو شتێک بە دەست تاقی بکەرەوە، لەوانەش حاڵەتەکانی هەڵە: فۆڕمێکی بەتاڵ، شوێنێک کە بوونی نییە، ئاهەنگێک بۆ هونەرمەندێک کە بوونی نییە.
8. README بنووسە و push بکە بۆ GitHub.

### پارچە کۆدی یارمەتیدەر

جیاکردنەوەی ئاهەنگە داهاتوو و ڕابردووەکانی شوێنێک:

```python
from datetime import datetime

now = datetime.now()
upcoming = db.session.execute(
    db.select(Show).where(Show.venue_id == venue.id, Show.start_time > now).order_by(Show.start_time)
).scalars().all()
past = db.session.execute(
    db.select(Show).where(Show.venue_id == venue.id, Show.start_time <= now).order_by(Show.start_time.desc())
).scalars().all()
```

گەڕانی بەشەکی بەبێ جیاوازیی پیتی گەورە و بچووک:

```python
term = request.form.get("search_term", "")
results = db.session.execute(
    db.select(Venue).where(Venue.name.ilike(f"%{term}%"))
).scalars().all()
```

بەکارهێنانی f-string لەناو `ilike()` دا سەلامەتە: SQLAlchemy هێشتا بەهاکە وەک پارامیتەر دەنێرێت. مەترسییەکە تەنها لە دروستکردنی **دەقی SQL ـی خاو** دایە بە دەستی خۆت.

- سڕینەوەی شوێن یان هونەرمەند لە پەڕەکەیەوە
