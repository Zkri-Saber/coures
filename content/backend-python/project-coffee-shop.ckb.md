قاوەخانەیەکی ناوچەکە لیستێکی دیجیتاڵیی خواردنەوە دەست پێ دەکات. کڕیاران دەتوانن سەیری خواردنەوەکان بکەن، قاوەسازەکان دەتوانن ڕەچەتەی تەواو ببینن، و بەڕێوەبەران دەتوانن خواردنەوە دروست بکەن و بیگۆڕن. ئەرکی تۆ: دروستکردنی **باکئێندی سەلامەت**، لەگەڵ ناسینەوە لە ڕێگەی دابینکەرێکی ناسنامەوە و **کۆنترۆڵی دەستگەیشتن لەسەر بنەمای ڕۆڵ**.

## چی دروست دەکەیت

API ـێکی Flask لەگەڵ بنکەدراوەیەکی خواردنەوەکان، کە هەر خاڵێکی کۆتایی بەپێی ئەوەی کێ بانگی دەکات پارێزراوە.

### مۆدێلی داتا

| خانە | جۆر | تێبینی |
| --- | --- | --- |
| `id` | ژمارەی تەواو | کلیلی سەرەکی |
| `title` | دەق | تایبەت (unique)، بۆ نموونە "Flat white" |
| `recipe` | لیستی JSON | پێکهاتەکان، هەر یەکێکیان `name`، `color` و `parts` ـی هەیە، وەک `[{"name": "milk", "color": "white", "parts": 2}]` |

دوو مێتۆد بدە بە مۆدێلەکە:

- `short()`: خواردنەوەکە لەگەڵ ڕەچەتە بە **ڕەنگ و بەشەکان تەنها**، بۆ لیستە گشتییەکە
- `long()`: خواردنەوەکە لەگەڵ **ڕەچەتەی تەواو**، لەوانە ناوی پێکهاتەکان

### ڕۆڵەکان و مۆڵەتەکان

| ڕۆڵ | مۆڵەتەکان |
| --- | --- |
| گشتی (بەبێ چوونەژوورەوە) | هیچ |
| قاوەساز (Barista) | `get:drinks-detail` |
| بەڕێوەبەر | `get:drinks-detail`، `post:drinks`، `patch:drinks`، `delete:drinks` |

### خاڵەکانی کۆتایی

| ڕێگا و ڕێڕەو | مۆڵەت | دەیگەڕێنێتەوە |
| --- | --- | --- |
| `GET /drinks` | گشتی | `{"success": true, "drinks": [...]}` بە بەکارهێنانی `short()` |
| `GET /drinks-detail` | `get:drinks-detail` | هەموو خواردنەوەکان بە بەکارهێنانی `long()` |
| `POST /drinks` | `post:drinks` | خواردنەوە نوێیەکە، بە بەکارهێنانی `long()` |
| `PATCH /drinks/<id>` | `patch:drinks` | خواردنەوە نوێکراوەکە، بە بەکارهێنانی `long()` |
| `DELETE /drinks/<id>` | `delete:drinks` | `{"success": true, "delete": id}` |

## دابینکەری ناسنامەکەت ئامادە بکە

هەر دابینکەرێک بەکاربهێنە کە تۆکنی دەستگەیشتنی JWT ـی RS256 دەردەکات و پشتگیریی RBAC دەکات؛ پلانی بێبەرامبەری Auth0 هەڵبژاردەیەکی باوە. لە داشبۆردی دابینکەرەکەتدا:

1. **API ـێک دروست بکە** لەگەڵ ناسێنەرێک (**بینەر** - audience)، بۆ نموونە `coffee-api`، و واژووکردنی RS256.
2. **RBAC چالاک بکە** بۆ API ـەکە و ئەو هەڵبژاردەیەی کە **مۆڵەتەکان زیاد دەکات بۆ تۆکنی دەستگەیشتن**.
3. **چوار مۆڵەتەکە دروست بکە** کە لە سەرەوە لیست کراون.
4. **دوو ڕۆڵ دروست بکە**، قاوەساز و بەڕێوەبەر، و مۆڵەتەکانیان پێ بدە.
5. **دوو بەکارهێنەری تاقیکردنەوە دروست بکە** و ڕۆڵێک بدە بە هەر یەکێکیان.
6. **تۆکنێکی دەستگەیشتن وەربگرە** بۆ هەر بەکارهێنەرێک (زۆربەی دابینکەران چوونەژوورەوەیەکی تاقیکردنەوە یان ڕێگایەک بۆ وەرگرتنی تۆکن بۆ تاقیکردنەوە پێشکەش دەکەن). یەکێکیان بلکێنە لە [jwt.io](https://jwt.io) بۆ پشکنینی ئەوەی داوای `permissions` تێدایە.

دۆمەینی دابینکەرەکەت و بینەرەکە لە گۆڕاوەکانی ژینگەدا دابنێ، نەک لە کۆدەکەتدا.

## مەرجەکان

| بوار | پرۆژەکەت چاوەڕوانییەکان پڕ دەکاتەوە کاتێک... |
| --- | --- |
| **مامەڵەکردن لەگەڵ تۆکن** | `auth.py` سەرپەڕەی `Authorization: Bearer` دەخوێنێتەوە، واژووی RS256 بە کلیلە گشتییەکانی دابینکەرەکە پشتڕاست دەکاتەوە، و بەسەرچوون، بینەر و دەرکەر دەپشکنێت |
| **مۆڵەتەکان** | decorator ـێکی `requires_auth(permission)` داوای `permissions` دەپشکنێت، و هەموو خاڵێکی کۆتایی مۆڵەتی دروست بەکاردەهێنێت |
| **کۆدەکانی دۆخ** | تۆکنی ون، شێواو، نادروست یان بەسەرچوو **401** دەگەڕێنێتەوە؛ تۆکنی دروست بەبێ مۆڵەتەکە **403** دەگەڕێنێتەوە |
| **خاڵەکانی کۆتایی** | هەر پێنج خاڵە کۆتاییەکە وەک دیاریکراو کار دەکەن، و `short()` و `long()` بە دروستی بەکارهاتوون |
| **هەڵەکان** | چارەسەرکەری هەڵەی JSON بۆ 400، 401، 403، 404، 422 و 500 هەیە، لەگەڵ چارەسەرکەرێک بۆ `AuthError` ـەکەت |
| **پشتڕاستکردنەوەی داتا** | `POST` و `PATCH` ناونیشان و ڕەچەتەی ون یان شێواو بە 400 یان 422 ڕەت دەکەنەوە |
| **تاقیکردنەوەکان** | تاقیکردنەوەی خۆکار، یان کۆمەڵەیەکی هەناردەکراوی Postman یان Bruno، دەیسەلمێنن کە هەر ڕۆڵێک ئەنجامی دروست لەسەر هەموو خاڵێکی کۆتایی وەردەگرێت، لەوانە حاڵەتەکانی 401 و 403 |
| **ئاسایش** | هیچ نهێنییەک لە کۆگاکەدا نییە؛ CORS سنووردارە بۆ ئەو سەرچاوانەی پێویستیان پێیەتی؛ دۆخی debug بە شێوەی بنەڕەتی کوژاوەتەوە |
| **README** | ئامادەکردن، گۆڕاوەکانی ژینگە، ڕۆڵ و مۆڵەتەکان، چۆنیەتیی وەرگرتنی تۆکنی تاقیکردنەوە ڕوون دەکاتەوە، و هەموو خاڵێکی کۆتایی بەڵگەنامە دەکات |

## هەنگاوە پێشنیارکراوەکان

1. سەرەتا مۆدێلەکە و هەر پێنج خاڵە کۆتاییەکە **بەبێ** ناسینەوە دروست بکە، و بە curl تاقییان بکەرەوە.
2. دابینکەری ناسنامە، ڕۆڵەکان و بەکارهێنەران ئامادە بکە.
3. `auth.py` بنووسە، بە پەیڕەوکردنی وانەکانی ناسینەوە و ڕێگەپێدان.
4. `@requires_auth(...)` زیاد بکە بۆ هەر خاڵێکی کۆتایی، پاشان هەموو ڕۆڵێک لەسەر هەموو خاڵێکی کۆتایی تاقی بکەرەوە:

| | گشتی | قاوەساز | بەڕێوەبەر |
| --- | --- | --- | --- |
| `GET /drinks` | 200 | 200 | 200 |
| `GET /drinks-detail` | 401 | 200 | 200 |
| `POST /drinks` | 401 | 403 | 201 یان 200 |
| `PATCH /drinks/1` | 401 | 403 | 200 |
| `DELETE /drinks/1` | 401 | 403 | 200 |

5. README بنووسە و بینێرە بۆ GitHub.

### ئاماژەکان

- ڕەچەتەکە لە ستوونێکی `JSON` دا هەڵبگرە (`from sqlalchemy import JSON`) یان وەک دەقێکی JSON لە ستوونێکی دەقدا.
- تۆکنەکان بەسەردەچن، زۆرجار دوای چەند کاتژمێرێک. ئەگەر تاقیکردنەوەکان لەناکاو بە 401 شکست بهێنن، تۆکنێکی نوێ وەربگرە.
- بۆ تاقیکردنەوە بەبێ ئینتەرنێت، ڕێگای mock لە وانەی ڕێگەپێداندا بەکاربهێنە.

## ئامانجە زیادەکان

- **Dockerfile** ـێک زیاد بکە بۆ ئەوەی API بە `docker build` و `docker run` کار بکات، و بەرنامەکە بە Gunicorn پێشکەش بکات
- `docker-compose.yml` زیاد بکە بۆ دەستپێکردنی API و PostgreSQL پێکەوە
- خاڵەکانی کۆتایی نووسین بە Flask-Limiter سنووردار بکە
- هەموو 401 و 403 ـێک تۆمار بکە لەگەڵ کات، خاڵی کۆتایی و id ـی بەکارهێنەر (هەرگیز تۆکنەکە نا)
