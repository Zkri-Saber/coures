پۆلەکەت دەیەوێت شەوانی پرسیار و وەڵام (trivia) ڕێک بخات، و پێویستی بە باکئێندێکە بۆ یارییەکە. لەم پرۆژەیەدا **REST API ـێکی تاقیکراوە و بەڵگەنامەکراو** دروست دەکەیت کە بەڕێوەبردنی پرسیارەکان دەکات و تاقیکردنەوە (quiz) پێشکەش دەکات.

## چی دروست دەکەیت

API ـێکی Flask کە PostgreSQL پشتگیری دەکات، بەم تایبەتمەندییانەوە:

1. لیستکردنی پرسیارەکان، بە پەڕەبەندی، لەگەڵ پۆلەکانیان
2. سڕینەوەی پرسیارێک
3. زیادکردنی پرسیارێکی نوێ
4. گەڕان لە پرسیارەکاندا
5. لیستکردنی پرسیارەکانی یەک پۆل
6. یاریکردنی تاقیکردنەوە: وەرگرتنی پرسیاری هەڕەمەکی، بە دڵخواز لە یەک پۆلەوە، بەبێ دووبارەکردنەوەی هیچ پرسیارێک

هیچ مەرجێکی فرۆنتئێند نییە. بە curl، Postman یان Bruno، و بە تاقیکردنەوەی خۆکار تاقی دەکەیتەوە. (ئەگەر خولی وێبت تەواو کردووە، دروستکردنی فرۆنتئێندێکی بچووک ئامانجێکی زیادەی باشە.)

## مۆدێلی داتا

| مۆدێل | خانەکان |
| --- | --- |
| **Category** | `id`، `type` (بۆ نموونە "Science"، "History") |
| **Question** | `id`، `question`، `answer`، `category` (id ـی پۆلێک)، `difficulty` (1 تا 5) |

چەند پۆلێک و لانیکەم 20 پرسیار وەک داتای سەرەتایی (seed data) دروست بکە، لە فایلێکی SQL یان سکریپتێکی پایتۆنی seed دا، بۆ ئەوەی API شتێکی هەبێت پێشکەشی بکات.

## خاڵە کۆتاییە پێویستەکان

| ڕێگا و ڕێڕەو | چی دەکات |
| --- | --- |
| `GET /categories` | هەموو پۆلەکان، وەک dictionary ـێکی `{id: type}` |
| `GET /questions?page=1` | 10 پرسیار بۆ هەر پەڕەیەک، لەگەڵ کۆی ژمارەکە و هەموو پۆلەکان |
| `DELETE /questions/<id>` | سڕینەوەی یەک پرسیار |
| `POST /questions` | دروستکردنی پرسیارێک لە `question`، `answer`، `category` و `difficulty` |
| `POST /questions/search` | ئەو پرسیارانەی دەقەکەیان `searchTerm` ـی تێدایە، بەبێ گرنگیدان بە پیتی گەورە و بچووک |
| `GET /categories/<id>/questions` | پرسیارەکانی یەک پۆل |
| `POST /quizzes` | بە پێدانی `previous_questions` (لیستێک لە id) و `quiz_category`، یەک پرسیاری هەڕەمەکی بگەڕێنەوە کە هێشتا نەپرسراوە، یان هیچ کاتێک پرسیارەکان تەواو دەبن |

نموونەی داواکاری و وەڵامی تاقیکردنەوە:

```bash
curl -X POST http://127.0.0.1:5000/quizzes \
  -H "Content-Type: application/json" \
  -d '{"previous_questions": [4, 12], "quiz_category": {"id": 1, "type": "Science"}}'
```

```json
{
  "success": true,
  "question": { "id": 21, "question": "What is the heaviest organ in the human body?", "answer": "The liver", "category": 1, "difficulty": 4 }
}
```

بڕیار بدە (و بەڵگەنامەی بکە) ڕاژەخوازێک چۆن داوای پرسیار لە **هەموو** پۆلەکان دەکات، بۆ نموونە `"quiz_category": {"id": 0}`.

## مەرجەکان

| بوار | پرۆژەکەت چاوەڕوانییەکان پڕ دەکاتەوە کاتێک... |
| --- | --- |
| **خاڵەکانی کۆتایی** | هەموو خاڵە کۆتاییە پێویستەکان کار دەکەن، ڕێگای HTTP ـی دروست بەکاردەهێنن، و پەیڕەوی ناونانی REST دەکەن |
| **وەڵامەکان** | وەڵامەکان JSON ـن بە شێوەیەکی یەکگرتوو (بۆ نموونە خانەی `success`) و کۆدی دۆخی دروست |
| **پەڕەبەندی** | `GET /questions` بۆ هەر پەڕەیەک 10 دەگەڕێنێتەوە و بۆ پەڕەکانی دوای کۆتایی 404 |
| **هەڵەکان** | چارەسەرکەری هەڵەی JSON لانیکەم بۆ 400، 404، 422 و 500 هەیە، و API هەرگیز پەڕەی هەڵەی HTML ناگەڕێنێتەوە |
| **CORS** | CORS ڕێکخراوە، لەگەڵ ڕوونکردنەوەیەک لە README دا کە کام سەرچاوانە ڕێگەپێدراون |
| **تاقیکردنەوەکان** | تاقیکردنەوەکانی `unittest` **هەموو خاڵێکی کۆتایی** دادەپۆشن، لانیکەم یەک تاقیکردنەوەی سەرکەوتن **و** یەک تاقیکردنەوەی هەڵە بۆ هەر یەکێکیان، لەسەر بنکەدراوەیەکی جیای تاقیکردنەوە |
| **بەڵگەنامە** | README ئامادەکردن، پڕکردنەوەی بنکەدراوە، جێبەجێکردنی ڕاژەکار و تاقیکردنەوەکان ڕوون دەکاتەوە، و هەموو خاڵێکی کۆتایی بە پارامیتەرەکانی داواکاری، وەڵامێکی نموونە و هەڵە ئەگەرییەکانەوە بەڵگەنامە دەکات |
| **کوالیتیی کۆد** | کۆد خوێندراوە، ڕێکخراوە (مۆدێلەکان جیان لە بەرنامەکە)، کارگەی بەرنامە بەکاردەهێنێت، و هیچ نهێنییەک یان کۆدی بەکارنەهاتووی تێدا نییە |

## هەنگاوە پێشنیارکراوەکان

1. بنکەدراوەکانی `trivia` و `trivia_test` دروست بکە و پڕیان بکەرەوە.
2. `models.py` و کارگەیەکی بەرنامە لە `app.py` دا بنووسە، بە دووبارە بەکارهێنانەوەی پێکهاتەی ڕەفەی کتێب.
3. هەر جارە یەک خاڵی کۆتایی دروست بکە. بۆ هەر یەکێکیان: تاقیکردنەوەکە بنووسە، کۆدەکە بنووسە، بە curl بیپشکنە، بەڵگەنامەی بکە. تاقیکردنەوە و بەڵگەنامە بۆ کۆتایی جێ مەهێڵە.
4. چارەسەرکەرەکانی هەڵە و تاقیکردنەوەکانیان زیاد بکە.
5. خشتەی مەرجەکان دووبارە بخوێنەوە و هەر دێڕێک بپشکنە.
6. بینێرە (push) بۆ GitHub.

### ئاماژەکان

- بۆ پرسیارێکی هەڕەمەکیی نەپرسراو، بە `Question.id.not_in(previous_questions)` فلتەر بکە، پاشان بە `random.choice()` لەسەر ئەنجامەکان بە هەڕەمەکی هەڵبژێرە، یان با PostgreSQL بیکات بە `order_by(func.random()).limit(1)`.
- بۆ گەڕاندنەوەی پۆلەکان وەک `{id: type}`، dictionary comprehension بەکاربهێنە: `{c.id: c.type for c in categories}`.
- حاڵەتی سنووریی خاڵی کۆتایی تاقیکردنەوەکە تاقی بکەرەوە: چی ڕوودەدات کاتێک هەموو پرسیارێک پرسراوە؟

## ئامانجە زیادەکان

- `GET /questions/<id>` و `PATCH /questions/<id>` زیاد بکە
- خانەیەکی `rating` بۆ پرسیارەکان و ڕێگایەک بۆ ڕیزکردن بەپێی ئەو زیاد بکە
- خشتەی پێشەنگەکان (leaderboard) زیاد بکە: `POST /scores` و `GET /scores`
- پەڕەیەکی وێبی بچووک دروست بکە کە بە API ـەکەت تاقیکردنەوەکە یاری دەکات
