لەم بەشەدا هەژمار، چوونەژوورەوە و مۆڵەت زیاد دەکەیت بۆ بەرنامەکانت. پێش نووسینی هیچ کۆدێک، پێویستت بە زاراوەیەکی هاوبەشە بۆ **ئاسایش**، و وێنەیەکی ڕوون لەو ئامرازانەی بەکاردێن.

## سێگۆشەی CIA

ئاسایشی زانیاری سێ تایبەتمەندی دەپارێزێت:

| تایبەتمەندی | مانا | نموونەی شکست |
| --- | --- | --- |
| **نهێنی** (Confidentiality) | تەنها کەسە دروستەکان دەتوانن داتاکە ببینن | لیستێکی کڕیاران کە دزراوەتە دەرەوە |
| **تەواوی** (Integrity) | داتا بەبێ ڕێگەپێدان ناگۆڕدرێت | کەسێک نمرەکەی خۆی لە بنکەدراوەدا دەگۆڕێت |
| **بەردەستبوون** (Availability) | سیستەمەکە کار دەکات کاتێک خەڵک پێویستیان پێیەتی | ماڵپەڕێک کە بە لافاوێک لە هاتوچۆ لە کار دەخرێت |

هەموو بڕیارێکی ئاسایش لانیکەم یەکێک لەمانە دەپارێزێت.

## زاراوە سەرەکییەکان

- **سامان** (Asset): شتێک کە شایەنی پاراستنە، وەک داتای بەکارهێنەر، پارە یان ناوبانگت.
- **کەلێن** (Vulnerability): لاوازییەک، وەک پشکنینێکی مۆڵەتی ون.
- **هەڕەشە** (Threat): کەسێک یان شتێک کە دەتوانێت لاوازییەک بقۆزێتەوە.
- **مەترسی** (Risk): ئەگەری ڕوودانی، لێکدراو لە ئەوەی چەندە خراپ دەبێت.

## ناسینەوە بەرامبەر ڕێگەپێدان

ئەم دوو وشەیە ئاسان تێکەڵ دەکرێن، و هەردووکیان لە هەموو وانەیەکی ئەم بەشەدا دەردەکەون:

- **ناسینەوە** (Authentication, AuthN): *تۆ کێیت؟* سەلماندنی ناسنامە، بۆ نموونە بە چوونەژوورەوە.
- **ڕێگەپێدان** (Authorization, AuthZ): *ڕێگەت پێ دراوە چی بکەیت؟* پشکنینی مۆڵەتەکان.

لە فڕۆکەخانەدا، پاسپۆرتەکەت تۆ **دەناسێنێت**. کارتی سواربوونەکەت **ڕێگەت پێ دەدات** سواری یەک گەشتی دیاریکراو بیت.

## ئەو بنەمایانەی جێبەجێیان دەکەیت

- **کەمترین دەسەڵات** (least privilege): بە هەر بەکارهێنەر، بەرنامە و هەژمارێکی بنکەدراوە تەنها ئەو دەستگەیشتنە بدە کە پێویستییەتی، نە زیاتر.
- **بەرگری بە قووڵی** (defense in depth): چەند چینێک پاراستن بەکاربهێنە، بۆ ئەوەی یەک هەڵە کوشندە نەبێت.
- **بە سەلامەتی شکست بهێنە** (fail securely): کاتێک شتێک تێکدەچێت، دەستگەیشتن ڕەت بکەرەوە لە جیاتی ڕێگەدان.
- **هەرگیز متمانە بە ڕاژەخواز مەکە:** هەر شتێک لە وێبگەڕ یان بەرنامەکەوە بێت دەکرێت ساختە بکرێت. باکئێند دەبێت هەموو شتێک خۆی بپشکنێت.

## کۆدکردن، شێوەگۆڕین و هاشکردن

ئەم سێیانە زۆرجار تێکەڵ دەکرێن، و تێکەڵکردنیان دەبێتە هۆی دزەکردنی ڕاستەقینە.

| | چی دەکات | دەگەڕێتەوە؟ | بەکاری بهێنە بۆ |
| --- | --- | --- | --- |
| **کۆدکردن** (Encoding، وەک Base64) | شێوەی داتا دەگۆڕێت بۆ ئەوەی بگوازرێتەوە | بەڵێ، لەلایەن **هەر کەسێکەوە** | گواستنەوە، نەک نهێنی |
| **شێوەگۆڕین** (Encryption، وەک AES، TLS) | داتا بە کلیلێک تێکدەدات | بەڵێ، بە **کلیلەکە** | نهێنی هێشتنەوەی داتا |
| **هاشکردن** (Hashing، وەک SHA-256، scrypt) | داتا دەکات بە پەنجەمۆرێکی قەبارە-جێگیر | **نەخێر** | پشکنینی وشەی نهێنی و تەواویی فایل |

```python
>>> import base64
>>> base64.b64encode(b"hello").decode()
'aGVsbG8='
>>> base64.b64decode("aGVsbG8=").decode()
'hello'
```

Base64 **ئاسایش نییە**: هەر کەسێک دەتوانێت بیکاتەوە. دەبینیت ئەمە گرنگە کاتێک سەیری تۆکنەکان دەکەین.

## دوو جۆر شێوەگۆڕین

- **هاوتەریب** (Symmetric): هەمان کلیلی نهێنی شێوەگۆڕین دەکات و دەیکاتەوە. خێرایە، بەڵام هەردوو لا دەبێت نهێنییەکە بە سەلامەتی هاوبەش بکەن.
- **ناهاوتەریب** (Asymmetric): **جووتێک کلیل**. **کلیلی گشتی** دەکرێت لەگەڵ هەر کەسێک هاوبەش بکرێت؛ **کلیلی تایبەت** نهێنی دەمێنێتەوە. ئەوەی کلیلێک قفڵی دەکات، تەنها ئەوی تر دەتوانێت بیکاتەوە. ئەمە **واژووی دیجیتاڵی**ش ڕێگەپێدراو دەکات: بە کلیلی تایبەت واژوو بکە، و هەر کەسێک دەتوانێت بە کلیلی گشتی پشتڕاستی بکاتەوە.

**HTTPS** هەردووکیان بەکاردەهێنێت: نهێنیکاریی ناهاوتەریب بۆ دامەزراندنی پەیوەندییەک بە سەلامەتی، پاشان شێوەگۆڕینی هاوتەریبی خێرا بۆ داتاکە. هەمیشە بەرنامە ڕاستەقینەکان لەسەر HTTPS پێشکەش بکە.

## نهێنییەکان لە کۆدەکەت دوور بخەرەوە

وشەی نهێنی، کلیلەکانی API و URL ـی بنکەدراوە کە وشەی نهێنییان تێدایە **هەرگیز** نابێت commit بکرێن بۆ Git، تەنانەت لە کۆگایەکی تایبەتیشدا. لە **گۆڕاوەکانی ژینگە** (environment variables) بیانخوێنەوە:

```python
import os

DATABASE_URL = os.environ["DATABASE_URL"]
```

بۆ گەشەپێدانی ناوخۆیی، لە فایلێکی `.env` دا هەڵیان بگرە کە لە `.gitignore` دا لیست کراوە، و بە پاکێجی `python-dotenv` باری بکە. فایلێکی `.env.example` هاوبەش بکە کە *ناوی* گۆڕاوەکانی تێدایە بەڵام هیچ بەهایەکی ڕاستەقینەی تێدا نییە.
