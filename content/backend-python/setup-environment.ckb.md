پێش نووسینی هیچ کۆدێک، با ئەو ئامرازانە ئامادە بکەین کە بۆ هەموو بەشەکانی تری بەرنامەکە بەکاریان دەهێنیت. کاتی خۆت بدە: ئامادەکردنێکی پاک کاتژمێرەها لە هەڵەی سەرلێشێوێنەر لە داهاتوودا دەپارێزێت.

## 1. پایتۆن بپشکنە

تێرمیناڵێک بکەرەوە و ئەمە جێبەجێ بکە:

```bash
python3 --version
```

لەسەر ویندۆز، لە جیاتی ئەوە `py --version` تاقی بکەرەوە. پێویستت بە **3.10 یان نوێتر** هەیە. ئەگەر نیتە، لە [python.org](https://www.python.org/downloads/) دایبمەزرێنە. لەسەر ویندۆز، لە دامەزرێنەرەکەدا نیشانەی **Add python.exe to PATH** دابنێ.

## 2. پڕۆژەیەک و ژینگەیەکی مەجازی دروست بکە

**ژینگەی مەجازی** (virtual environment) پاکێجەکانی هەر پڕۆژەیەک جیا دەهێڵێتەوە، بۆیە وەشانەکانی پڕۆژەیەک پڕۆژەیەکی تر تێکنادەن.

```bash
mkdir todoapp
cd todoapp
python3 -m venv .venv
```

چالاکی بکە. هەر جارێک تێرمیناڵێکی نوێ بۆ ئەم پڕۆژەیە دەکەیتەوە ئەمە دەکەیت:

```bash
# macOS and Linux
source .venv/bin/activate

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
```

پرۆمپتەکەت ئێستا بە `(.venv)` دەست پێ دەکات. پاکێجەکانی ئەم کۆرسە دابمەزرێنە:

```bash
pip install flask flask-sqlalchemy flask-migrate "psycopg[binary]"
pip freeze > requirements.txt
```

`psycopg` ـە **درایڤەر** ـەکەیە کە ڕێگە بە پایتۆن دەدات قسە لەگەڵ PostgreSQL بکات. `requirements.txt` وەشانە وردەکان تۆمار دەکات، بۆیە هەر کەسێک دەتوانێت بە `pip install -r requirements.txt` ژینگەکەت دووبارە دروست بکاتەوە.

## 3. PostgreSQL کار پێ بکە

**یەکێک** لەم هەڵبژاردانە هەڵبژێرە.

### هەڵبژاردەی A: Docker (پێشنیارکراو)

[Docker](https://www.docker.com/products/docker-desktop/) نەرمەکاڵا لەناو **کۆنتەینەری** (container) جیاکراوەدا کار پێ دەکات. یەک فەرمان ڕاژەکارێکی PostgreSQL ـت دەداتێ:

```bash
docker run --name pg -e POSTGRES_PASSWORD=postgres -p 5432:5432 \
  -v pgdata:/var/lib/postgresql/data -d postgres:17
```

- `-e POSTGRES_PASSWORD=postgres` وشەی نهێنیی بەکارهێنەری `postgres` دیاری دەکات.
- `-p 5432:5432` بنکەدراوەکە لەسەر کۆمپیوتەرەکەت لە پۆرتی 5432 دا بەردەست دەکات.
- `-v pgdata:...` داتاکان لە volume ـێکی ناودار هەڵدەگرێت، بۆیە دوای ڕیستارتکردن دەمێنێتەوە.

دواتر، `docker stop pg` و `docker start pg` بەکاربهێنە بۆ وەستاندن و دەستپێکردنەوەی.

### هەڵبژاردەی B: PostgreSQL ڕاستەوخۆ دابمەزرێنە

لە [postgresql.org/download](https://www.postgresql.org/download/) دایبگرە و دامەزرێنەرەکە پەیڕەو بکە. ئەو وشە نهێنییە لەبیر بێت کە بۆ بەکارهێنەری `postgres` هەڵیدەبژێریت.

## 4. بنکەدراوەیەک دروست بکە

ڕاژەخوازی هێڵی فەرمانی PostgreSQL، واتە `psql`، بکەرەوە:

```bash
# With Docker
docker exec -it pg psql -U postgres

# With a direct install
psql -U postgres
```

پاشان بنکەدراوەیەک بۆ بەرنامەی لیستی کارەکان دروست بکە و دەربچۆ:

```sql
CREATE DATABASE todoapp;
\q
```

## 5. Git ئامادە بکە

فایلێکی `.gitignore` دروست بکە تا ژینگە مەجازییەکەت یان نهێنییەکانت commit نەکەیت:

```text
.venv/
__pycache__/
.env
*.db
```

پاشان `git init` جێبەجێ بکە و یەکەم commit ـت بکە.

## 6. دەستکاریکەرێک هەڵبژێرە

هەر دەستکاریکەرێکی کۆد کار دەکات. [VS Code](https://code.visualstudio.com) لەگەڵ پێوەکراوی **Python** هەڵبژاردەیەکی بەخۆڕایی و بەناوبانگە. ئاراستەی بکە بۆ وەرگێڕی (interpreter) ـی `.venv` ـەکەت تا لە پاکێجە دامەزراوەکانت تێبگات.

> ئەگەر شتێک کار ناکات، هەر هەنگاوێک بە وردی دووبارە بخوێنەوە، پاشان ڕێگای "وەرگرتنی یارمەتی" بەکاربهێنە: هەڵەکە بخوێنەوە، بەدوایدا بگەڕێ، پاشان بپرسە.

:::quiz
Q: بۆچی ژینگەیەکی مەجازی بەکاردەهێنیت؟
- [ ] پایتۆن خێراتر کار پێ دەکات
- [x] پاکێج و وەشانەکانی هەر پڕۆژەیەک جیا دەهێڵێتەوە
- [ ] بۆ بەکارهێنانی PostgreSQL پێویستە
Why: پڕۆژە جیاوازەکان لەوانەیە پێویستیان بە وەشانی جیاوازی پاکێج بێت. ژینگەی مەجازی لێکیان جیا دەکاتەوە.

Q: `pip freeze > requirements.txt` چی دەکات؟
- [x] وەشانە وردەکانی پاکێجە دامەزراوەکان لە فایلێکدا پاشەکەوت دەکات
- [ ] pip لە دامەزراندنی هەر شتێکی تر ڕادەگرێت
- [ ] پاکێجە بەکارنەهاتووەکان دەسڕێتەوە
Why: فایلەکە ڕێگە بە تۆ یان هەر کەسێکی تر دەدات بە `pip install -r requirements.txt` ڕێک هەمان وەشانەکان دووبارە دابمەزرێنێتەوە.
:::
