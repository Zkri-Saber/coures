گەشەپێدەران زۆرجار بیر لەوە دەکەنەوە بەرنامەیەک *دەبێت* چۆن بەکاربهێنرێت. هێرشبەران بیر لەوە دەکەنەوە *دەکرێت* چۆن خراپ بەکاربهێنرێت. بۆ دروستکردنی نەرمەکاڵای سەلامەت، پێویستە لە نێوان هەردوو بۆچووندا بگۆڕیت. ئەم وانەیە فێرت دەکات وەک هێرشبەرێک بیر بکەیتەوە، و ئاسایش بخەیتە ناو شێوازی کارکردنتەوە.

> تەنها ئاسایشی ئەو سیستەمانە تاقی بکەرەوە کە هی خۆتن یان مۆڵەتی نووسراوت هەیە بۆ تاقیکردنەوەیان. هێرشکردنە سەر سیستەمی کەسانی تر نایاساییە، تەنانەت "تەنها بۆ بینین".

## نەخشەکێشانی هەڕەشە (Threat modeling)

پێش دروستکردنی تایبەتمەندییەک، چوار پرسیار بکە:

1. **چی دروست دەکەین؟** ڕەوتی داتا بکێشە: کێ چی دەنێرێت، لە کوێ هەڵدەگیرێت.
2. **چی دەکرێت تێکبچێت؟**
3. **چی دەکەین دەربارەی؟**
4. **ئایا کارێکی باشمان کرد؟**

لیستی پشکنینی **STRIDE** یارمەتی پرسیاری 2 دەدات:

| هەڕەشە | پرسیاری پێویست | پاراستن |
| --- | --- | --- |
| **S**poofing (خۆکردن بە کەسێکی تر) | ئایا کەسێک دەتوانێت خۆی بکات بە بەکارهێنەرێکی تر؟ | ناسینەوە |
| **T**ampering (دەستکاری) | ئایا دەکرێت داتا لە کاتی گواستنەوە یان هەڵگرتندا بگۆڕدرێت؟ | واژوو، HTTPS، پشتڕاستکردنەوەی داتا |
| **R**epudiation (نکۆڵیکردن) | ئایا کەسێک دەتوانێت نکۆڵی لە کردنی شتێک بکات؟ | تۆمارکردن (logging) |
| **I**nformation disclosure (ئاشکرابوونی زانیاری) | ئایا دەکرێت داتا بۆ کەسانی هەڵە بدزرێتە دەرەوە؟ | ڕێگەپێدان، شێوەگۆڕین |
| **D**enial of service (ڕێگریکردن لە خزمەتگوزاری) | ئایا دەکرێت خزمەتگوزارییەکە پڕ بکرێت و لە کار بخرێت؟ | سنووری داواکاری، پەڕەبەندی |
| **E**levation of privilege (بەرزکردنەوەی دەسەڵات) | ئایا بەکارهێنەرێک دەتوانێت دەسەڵاتێک بەدەست بهێنێت کە نابێت هەیبێت؟ | پشکنینی مۆڵەت |

لەسەر پرۆژەی قاوەخانەکەت تاقی بکەرەوە: بۆ هەر خاڵێکی کۆتایی، بە شەش پیتەکەدا بڕۆ.

## OWASP Top 10

**OWASP** (Open Worldwide Application Security Project) ڕێکخراوێکی ناقازانجە کە ڕێنمایی ئاسایشی بێبەرامبەر بڵاو دەکاتەوە. **Top 10** ـەکەی گرنگترین مەترسییەکانی ئاسایشی بەرنامەی وێب لیست دەکات. وەشانی ئێستا **OWASP Top 10:2025** ـە:

| # | مەترسی | نموونە لە API ـێکی Flask دا |
| --- | --- | --- |
| A01 | کۆنترۆڵی دەستگەیشتنی تێکشکاو | لەبیرکردنی `@requires_auth`، یان نەپشکنینی ئەوەی کێ خاوەنی تۆمارێکە |
| A02 | ڕێکخستنی هەڵەی ئاسایش | جێبەجێکردن بە `--debug` لە بەرهەمهێناندا، یان سیاسەتی CORS ـی `*` لەسەر API ـێک کە چوونەژوورەوەی هەیە |
| A03 | شکستەکانی زنجیرەی دابینکردنی نەرمەکاڵا | دامەزراندنی پاکێجێکی زیانبەخش یان بەسەرچوو |
| A04 | شکستەکانی نهێنیکاری | هەڵگرتنی وشەی نهێنی بە هاشێکی خێرا، یان تێپەڕاندنی HTTPS |
| A05 | تێهەڵکێشان (Injection) | دروستکردنی SQL بە f-string لە داتای بەکارهێنەرەوە |
| A06 | دیزاینی ناسەلامەت | هیچ سنوورێک بۆ چوونەژوورەوە نییە، بۆیە دەکرێت وشەی نهێنی بێکۆتا مەزەندە بکرێت |
| A07 | شکستەکانی ناسینەوە | نەپشکنینی بەسەرچوون، بینەر یان ئەلگۆریتمی تۆکنێک |
| A08 | شکستەکانی تەواویی نەرمەکاڵا یان داتا | متمانەکردن بە داتا یان نوێکارییەک کە پشتڕاست نەکراوەتەوە |
| A09 | شکستەکانی تۆمارکردن و ئاگادارکردنەوەی ئاسایش | هیچ تۆمارێک نییە بۆ چوونەژوورەوەی شکستخواردوو یان هەڵەی مۆڵەت |
| A10 | مامەڵەی هەڵە لەگەڵ دۆخە نائاساییەکان | هەڵەگەلێک کە شوێنپێی ستاک (stack trace) دەدزنە دەرەوە، یان "بە کراوەیی شکست دەهێنن" و دەستگەیشتن دەدەن |

لەم بەرنامەیەدا پێشتر بەرگریت لە چەند دانەیەک لەمانە کردووە: پرسیاری پارامیتەرکراو (A05)، هاشکردنی وشەی نهێنی (A04)، پشتڕاستکردنەوەی تۆکن (A07) و پشکنینی مۆڵەت (A01).

## هەڵە باوەکانی Flask کە دەبێت خۆتیان لێ بپارێزیت

- **دۆخی debug لە بەرهەمهێناندا.** دۆزەرەوەی هەڵەی کارلێککار دەتوانێت ڕێگە بە هەر کەسێک بدات کۆد لەسەر ڕاژەکارەکەت جێبەجێ بکات. ڕاژەکارێکی بەرهەمهێنان بەکاربهێنە وەک Gunicorn، و هەرگیز `--debug` نا.
- **دزەپێکردنی هەڵەکان.** پەیامێکی گشتی بگەڕێنەوە بۆ ڕاژەخوازەکان؛ وردەکارییەکان لەسەر ڕاژەکار تۆمار بکە.
- **متمانەکردن بە داتای هاتوو.** جۆر، درێژی و بەها ڕێگەپێدراوەکان پشتڕاست بکەرەوە بۆ هەموو شتێک کە لە ڕاژەخوازەوە دێت: ناوەڕۆک، query string، سەرپەڕەکان و URL.
- **نهێنی لە Git دا.** گۆڕاوەکانی ژینگە بەکاربهێنە. ئەگەر نهێنییەک ڕۆژێک commit کرا، **دەستبەجێ بیگۆڕە**: سڕینەوەی فایلەکە لە مێژووی Git لای نابات.

## پرۆسەیەکی گەشەپێدانی سەلامەت

ئاسایش تایبەتمەندییەک نییە کە لە کۆتاییدا زیادی بکەیت. بیخەرە ناو هەموو هەنگاوێکەوە:

1. **دیزاین:** بۆ تایبەتمەندییە نوێیەکان نەخشەی هەڕەشە بکێشە.
2. **کۆد:** بەها بنەڕەتییە سەلامەتەکان بەکاربهێنە (ORM، پرسیاری پارامیتەرکراو، `requires_auth` لەسەر هەموو خاڵێکی کۆتایی ناگشتی).
3. **پێداچوونەوە:** با کەسێکی تر پێداچوونەوە بە هەموو گۆڕانکارییەکدا بکات، بە لەبەرچاوگرتنی ئاسایش.
4. **تاقیکردنەوە:** تاقیکردنەوە بۆ یاساکانی ئاسایش بنووسە، وەک وەڵامەکانی 401 و 403، نەک تەنها بۆ ڕێگا ئاساییەکە.
5. **پاشبەستەکان (Dependencies):** وەشانەکان لە `requirements.txt` دا جێگیر بکە و بۆ کەلێنە ناسراوەکان بیانپشکنە. `pip install pip-audit` پاشان `pip-audit` جێبەجێ بکە، و ئاگادارکردنەوەکانی Dependabot ـی GitHub چالاک بکە.
6. **چاودێری:** شکستەکانی ناسینەوە و هەڵەکان تۆمار بکە، و پێیاندا بچۆرەوە.

## ئاگادار بمێنەوە

هەموو ڕۆژێک کەلێنی نوێ دەدۆزرێتەوە. بەدوای ئەمانەدا بڕۆ:

- [ماڵپەڕی OWASP](https://owasp.org)، لەوانە زنجیرەی Cheat Sheet ـەکەی کە ڕێنمایی کردەیی تێدایە
- ئاگادارکردنەوەکانی ئاسایش بۆ ئەو پاکێجانەی بەکاریان دەهێنیت، وەک GitHub Advisory Database
- سیستەمی **CVE**، کە ناسنامەیەک وەک `CVE-2026-12345` دەدات بە هەر کەلێنێکی ناسراوی گشتی

ئەگەر ڕۆژێک کەلێنێکت لە نەرمەکاڵای کەسێکی تردا دۆزییەوە، بە تایبەتی ڕاپۆرتی بدە بە بەڕێوەبەرانی (**ئاشکراکردنی بەرپرسیارانە** - responsible disclosure) لە جیاتی بڵاوکردنەوەی.
