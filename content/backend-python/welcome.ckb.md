بەخێربێیت! لە چەند هەفتەی داهاتوودا، لە نووسینی سکریپتی پایتۆنەوە دەگەیتە دروستکردنی ئەو بەشەی بەرنامەکانی وێب کە بەکارهێنەران هەرگیز نایبینن بەڵام هەمیشە پشتی پێ دەبەستن: **باکئێند** (backend). ئەمە ئەو کۆدەیە کە داتا هەڵدەگرێت، یاساکان جێبەجێ دەکات، و وەڵامی داواکارییەکانی ماڵپەڕ و بەرنامەکانی مۆبایل دەداتەوە.

## چی دروست دەکەیت

بەرنامەکە بە **سێ پڕۆژەی پۆرتفۆلیۆ** لەسەر GitHub تەواو دەکەیت:

| پڕۆژە | چی دەسەلمێنێت |
| --- | --- |
| **ماڵپەڕی حیجزکردنی هونەرمەندان** | دەتوانیت بنکەدراوەیەکی پەیوەندیدار دیزاین بکەیت و بەرنامەیەکی وێبی تەواو لەسەری دروست بکەیت بە Flask و SQLAlchemy |
| **API ـی پرسیار و وەڵام (Trivia)** | دەتوانیت REST API دیزاین بکەیت، دروستی بکەیت، تاقیی بکەیتەوە و بەڵگەنامەی بۆ بنووسیت |
| **کافێی full stack** | دەتوانیت API بە ناسینەوە و مۆڵەتی پشتبەستوو بە ڕۆڵ بپارێزیت |

ئەمانە هەمان جۆری ئەو کارانەن کە گەشەپێدەرانی باکئێندی سەرەتایی هەموو ڕۆژێک دەیکەن، بۆیە نموونەی بەهێزن بۆ نیشاندان بە خاوەنکاران.

هەر وانەیەک تێکەڵەیەکە لە خوێندنەوە، کۆدێک کە خۆت دەینووسیت و جێبەجێی دەکەیت، و تاقیکردنەوەیەکی کورت. **کۆدەکان بنووسە لە جیاتی کۆپیکردنیان.** هێواشترە، بەڵام بەم شێوەیە نموونەکان لە مێشکتدا دەچەسپێن.

> کۆدەکانی ئەم بەرنامەیە بە ئینگلیزی ماونەتەوە، وەک ئەوەی پرۆگرامسازان لە هەموو جیهاندا دەینووسن. ڕوونکردنەوەکان بە کوردین.

## چیت پێویستە

- کۆمپیوتەرێک کە بتوانیت نەرمەکاڵای لەسەر دابمەزرێنیت (ویندۆز، ماک یان لینوکس)
- **پایتۆن 3.10 یان نوێتر**
- هەژمارێکی بەخۆڕایی **GitHub** بۆ ناردنی پڕۆژەکانت
- نزیکەی **6 تا 8 کاتژمێر لە هەفتەیەکدا**. بەم خێراییە لە نزیکەی دوو مانگدا تەواوی دەکەیت.

هەموو شتەکانی تر لە وانەی ئامادەکردنی ژینگە لە سەرەتای بەشی 2 دا دادەمەزرێنیت.

## چۆن سەرکەوتوو بیت

1. **خشتەیەک دابنێ.** کاتی دیاریکراوی خوێندن لە ڕۆژژمێرەکەتدا دابنێ، وەک هەر وانەیەکی تر.
2. **هەموو نموونەیەک دروست بکە.** خوێندنەوەی کۆد هەمان نووسینی نییە.
3. **چاوەڕێ بکە هەندێک جار گیر بخۆیت.** گیرخواردن بەشێکە لە پرۆگرامسازی، نەک نیشانەی ئەوەی ناتوانیت. وانەی داهاتوو بە وردی پیشانت دەدات چی بکەیت.
4. **زوو دەست بە پڕۆژەکان بکە.** هەر پڕۆژەیەک چەند دانیشتنێک دەخایەنێت. بۆ دوا کۆتایی هەفتە جێی مەهێڵە.
5. **زۆرجار کارەکانت commit بکە بۆ GitHub.** پاشەکەوتی یەدەگی و پۆرتفۆلیۆکەتە.
