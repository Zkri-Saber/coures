Welcome! Over the next few weeks you'll go from writing Python scripts to building the part of web applications that users never see but always depend on: the **backend**. That's the code that stores data, enforces the rules, and answers requests from websites and mobile apps.

## What you'll build

You'll finish the program with **three portfolio projects** on GitHub:

| Project | What it proves |
| --- | --- |
| **Artist booking site** | You can design a relational database and build a full web app on top of it with Flask and SQLAlchemy |
| **Trivia API** | You can design, build, test and document a REST API |
| **Coffee shop full stack** | You can secure an API with authentication and role-based permissions |

These are the same kinds of tasks junior backend developers do every day, so they make strong examples to show employers.

## What you need

- A computer where you can install software (Windows, macOS or Linux)
- **Python 3.10 or newer**
- A free **GitHub** account to submit your projects
- About **6 to 8 hours a week**. At that pace you'll finish in about two months.

You'll install everything else in the setup lesson at the start of Part 2.

## How to succeed

1. **Set a schedule.** Put fixed study times in your calendar, like any other class.
2. **Build every example.** Reading code is not the same as writing it.
3. **Expect to be stuck sometimes.** Being stuck is part of programming, not a sign you can't do it. The next lesson shows you exactly what to do about it.
4. **Start projects early.** Each project takes several sessions. Don't leave them to the last weekend.
5. **Commit your work to GitHub often.** It's your backup and your portfolio.

:::quiz
Q: What does the backend of a web application mainly do?
- [ ] Decide the colors and layout of the page
- [x] Store data, apply the rules of the app, and respond to requests
- [ ] Run only inside the user's browser
Why: The backend runs on a server. It manages data and logic, and frontends (websites and apps) talk to it through requests.

Q: What is the best way to learn from the code examples in this program?
- [ ] Read them carefully but don't run them
- [ ] Copy and paste them so there are no typos
- [x] Type them yourself, run them, and experiment with changes
Why: Typing and changing the code builds the muscle memory and understanding you need for the projects.
:::
