لە GitHub دا، پاشەکەوتکردنی گۆڕانکارییەک پێی دەوترێت **commit کردن**. هەر commit ـێک دەبێتە خاڵێکی هەمیشەیی لە مێژووی پڕۆژەکەتدا کە هەمیشە دەتوانیت بگەڕێیتەوە بۆی.

## دەستکاریکردنی فایلێک لە وێبگەڕدا

1. ڕیپۆزیتۆریی `hello-world` بکەرەوە و کلیک لە `README.md` بکە.
2. کلیک لە **ئایکۆنی قەڵەمەکە** (Edit this file) بکە لە سەرەوەی ڕاستی فایلەکە.
3. چەند دێڕێک دەربارەی خۆت زیاد بکە:

```markdown
# Hello, I'm Sara

I'm learning to use GitHub in Grade 10 Computer Science.

## Things I want to build
- A website about my favourite football team
- A game in Python
```

4. کلیک لە تابی **Preview** بکە تا ببینیت چۆن دەردەکەوێت.
5. کلیک لە **Commit changes...** بکە. پەنجەرەیەک دەکرێتەوە.
6. **پەیامێکی commit** بنووسە کە بڵێت چیت گۆڕیوە، بۆ نموونە `Add introduction to README`.
7. **Commit directly to the main branch** وەک خۆی هەڵبژێردراو بهێڵەرەوە و کلیک لە **Commit changes** بکە.

ئەمە دووەم commit ـتە. GitHub یەکەمیانی بۆ دروست کردیت کاتێک README ـەکەی دروست کرد.

## بینینی مێژووەکە

بگەڕێرەوە بۆ پەڕەی سەرەکیی ڕیپۆزیتۆرییەکە و کلیک لە ژمارەی commit ـەکان بکە (یان بەستەری **History** کاتێک سەیری فایلێک دەکەیت). هەموو commit ـێک دەبینیت، نوێترینیان سەرەتا، لەگەڵ پەیامەکەی، نووسەرەکەی و کاتەکەی.

کلیک لە هەر commit ـێک بکە تا بە وردی ببینیت چی گۆڕاوە:

- ئەو دێڕانەی بە **سەوز** و نیشانەی `+` پیشان دەدرێن زیاد کراون
- ئەو دێڕانەی بە **سوور** و نیشانەی `-` پیشان دەدرێن لابراون

ئەم پیشاندانە پێی دەوترێت **diff** (کورتکراوەی difference، واتە جیاوازی).

## زیادکردنی فایلی نوێ

لە پەڕەی سەرەکیی ڕیپۆزیتۆرییەکەوە، لیستی **Add file** بکەرەوە:

- **Create new file** ڕێگەت پێ دەدات ناوی فایلێک و ناوەڕۆکەکەی بنووسیت. نووسینی `/` لە ناوەکەدا فۆڵدەرێک دروست دەکات، بۆیە `notes/week1.md` فۆڵدەرێکی `notes` دروست دەکات کە فایلێکی تێدایە.
- **Upload files** ڕێگەت پێ دەدات فایل لە کۆمپیوتەرەکەتەوە ڕابکێشیت، وەک وێنە یان ماڵپەڕێکی تەواو.

هەردووکیان بە هەمان هەنگاوی **Commit changes** کۆتایی دێن.

## نووسینی پەیامی commit ـی باش

خۆی داهاتووت (و هاوتیمەکانت) ئەم پەیامانە دەخوێننەوە بۆ تێگەیشتن لە مێژووەکە. پەیامێکی باش کورتە و دەڵێت گۆڕانکارییەکە *چی* دەکات.

| بێسوود | بەسوود |
| --- | --- |
| `update` | `Add contact section to README` |
| `stuff` | `Fix broken link to my blog` |
| `asdfgh` | `Upload photos for the gallery page` |

ئامۆژگاری: وەک فەرمانێک بینووسە، وەک ئەوەی ڕستەی "ئەم commit ـە دەکات..." تەواو بکەیت. زۆربەی تیمەکان پەیامەکانی commit بە ئینگلیزی دەنووسن، بەڵام بۆ پڕۆژەکانی خۆت دەتوانیت کوردیش بەکاربهێنیت.

:::quiz
Q: لە diff ـێکدا، دێڕێکی سەوز کە بە `+` دەست پێ دەکات مانای چییە؟
- [x] دێڕەکە زیاد کراوە
- [ ] دێڕەکە لابراوە
- [ ] دێڕەکە هەڵەی تێدایە
Why: دێڕە سەوزەکانی `+` لەو commit ـەدا زیاد کراون. دێڕە سوورەکانی `-` لابراون.

Q: کامیان باشترین پەیامی commit ـە؟
- [ ] `changes`
- [ ] `final version!!!`
- [x] `Add list of favourite books to README`
Why: بە وردی دەڵێت commit ـەکە چی دەکات، بۆیە هەر کەسێک مێژووەکە بخوێنێتەوە بەبێ کردنەوەی فایلەکان تێدەگات.

Q: چۆن فۆڵدەرێک دروست دەکەیت کاتێک فایلێک لە GitHub زیاد دەکەیت؟
- [ ] کلیک لە دوگمەی "New folder" دەکەیت
- [x] `/` لە ناوی فایلەکەدا دەنووسیت، وەک `notes/week1.md`
- [ ] فۆڵدەر تەنها لەسەر کۆمپیوتەرەکەت دروست دەکرێت
Why: GitHub لەو ڕێڕەوەی دەینووسیت فۆڵدەر دروست دەکات. Git تەنها ئەو فۆڵدەرانە تۆمار دەکات کە لانیکەم یەک فایلیان تێدایە.
:::
