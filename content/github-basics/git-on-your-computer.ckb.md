دەستکاریکردن لە github.com بۆ گۆڕانکاریی بچووک باشە. بۆ پڕۆژەی ڕاستەقینە، کۆد لەسەر کۆمپیوتەرەکەی خۆت بە دەستکاریکەرێکی وەک VS Code دەنووسیت، پاشان **Git** بەکاردەهێنیت بۆ پاشەکەوتکردنی commit و ناردنیان بۆ GitHub.

## دوو ڕێگا بۆ دەستپێکردن

- **GitHub Desktop** ([desktop.github.com](https://desktop.github.com)) بەرنامەیەکە کە بۆ هەموو شتێکی ئەم وانەیە دوگمەی هەیە. ڕێگایەکی ئاسانە بۆ دەستپێکردن.
- **Git لە هێڵی فەرماندا** ئەوەیە کە زۆربەی پرۆگرامسازان بەکاری دەهێنن، و لەسەر هەموو کۆمپیوتەرێک بە هەمان شێوە کار دەکات. ئەم وانەیە فەرمانەکان پیشان دەدات، تا تێبگەیت هەر بەرنامەیەک چی بۆ دەکات.

## دامەزراندن و ئامادەکردنی Git

- **ویندۆز:** Git for Windows لە [git-scm.com](https://git-scm.com) دابگرە و هەڵبژاردە بنەڕەتییەکان قبوڵ بکە.
- **ماک:** Terminal بکەرەوە و بنووسە `git --version`. ئەگەر Git دانەمەزرابێت، ماکەکەت پێشنیاری دامەزراندنی دەکات.
- **لینوکس:** پاکێجی `git` بە بەڕێوەبەری پاکێجەکەت دابمەزرێنە.

پاشان بە Git بڵێ تۆ کێیت. ئەم وردەکارییانە بە هەموو commit ـێکەوە دەلکێن کە دەیکەیت:

```bash
git config --global user.name "Sara Ahmed"
git config --global user.email "you@example.com"
```

هەمان ناونیشانی ئیمەیڵی هەژماری GitHub ـەکەت بەکاربهێنە تا commit ـەکانت بە پرۆفایلەکەتەوە ببەسترێن.

## ڕێڕەوی کاری ڕۆژانە

```text
your folder ──git add──▶ staging area ──git commit──▶ local history ──git push──▶ GitHub
     ◀───────────────────────────────── git pull ───────────────────────────────────┘
```

### 1. Clone: کۆپیکردنی ڕیپۆزیتۆرییەکە بۆ کۆمپیوتەرەکەت

لە GitHub، ڕیپۆزیتۆرییەکەت بکەرەوە، کلیک لە دوگمە سەوزەکەی **Code** بکە و ناونیشانی HTTPS کۆپی بکە. پاشان:

```bash
git clone https://github.com/your-username/hello-world.git
cd hello-world
```

ئێستا فۆڵدەرێکی `hello-world` ـت هەیە کە هەموو فایلەکان و هەموو مێژووەکەی تێدایە.

### 2. شتێک بگۆڕە، پاشان دۆخەکە بپشکنە

`README.md` لە دەستکاریکەرەکەتدا دەستکاری بکە و پاشەکەوتی بکە. پاشان لە Git بپرسە چی گۆڕاوە:

```bash
git status
```

Git، `README.md` وەک *modified* (گۆڕاو) لیست دەکات.

### 3. Stage و commit

هەڵبژێرە کام گۆڕانکارییانە بچنە ناو commit ـی داهاتووەوە (ئەمە پێی دەوترێت **staging**)، پاشان commit ـیان بکە:

```bash
git add README.md
git commit -m "Add hobbies section to README"
```

`git add .` هەموو فایلە گۆڕاوەکانی ناو فۆڵدەرەکە بە یەکجار stage دەکات.

### 4. Push: ناردنی commit ـەکانت بۆ GitHub

```bash
git push
```

یەکەم جار، Git داوات لێ دەکات بچیتە ناو GitHub ـەوە، زۆرجار بە کردنەوەی پەنجەرەیەکی وێبگەڕ. وشەی نهێنیی ئاساییی GitHub ـەکەت کاتێک لە تێرمیناڵدا دەینووسیت کار ناکات؛ لە جیاتی ئەوە چوونەژوورەوەی وێبگەڕەکە بەکاربهێنە. Git for Windows ئەمە لە ڕێگەی ئامرازێکەوە دەکات بە ناوی Git Credential Manager. لەسەر سیستەمەکانی تر، دامەزراندنی GitHub CLI و جێبەجێکردنی `gh auth login` ئامادەی دەکات.

ڕیپۆزیتۆرییەکەت لە GitHub نوێ بکەرەوە: commit ـەکەت لەوێیە.

### 5. Pull: هێنانی ئەو گۆڕانکارییانەی لە شوێنی تر کراون

ئەگەر تۆ (یان هاوتیمێک) شتێکت لە GitHub گۆڕیوە، پێش دەستپێکردنی کار بیهێنە خوارەوە بۆ کۆمپیوتەرەکەت:

```bash
git pull
```

## دوورخستنەوەی فایلەکان لە Git

هەندێک فایل نابێت هاوبەش بکرێن، وەک وشەی نهێنی، داگرتنی گەورە یان ئەو فایلانەی دەستکاریکەرەکەت دروستیان دەکات. لە فایلێکدا بە ناوی `.gitignore` لە فۆڵدەری پڕۆژەکەتدا لیستیان بکە:

```text
secrets.txt
*.log
node_modules/
```

Git وا ڕەفتار دەکات وەک ئەوەی ئەو فایلانە بوونیان نەبێت.

> هەرگیز وشەی نهێنی یان کلیلی نهێنی commit مەکە، تەنانەت لە ڕیپۆزیتۆرییەکی تایبەتیشدا. ئەگەر بە هەڵە ڕوویدا، دەستبەجێ وشە نهێنییەکە بگۆڕە: سڕینەوەی فایلەکە دواتر لە مێژووەکە لای نابات.

:::quiz
Q: `git clone` چی دەکات؟
- [x] کۆپییەکی ڕیپۆزیتۆرییەکی GitHub، لەگەڵ مێژووەکەی، دادەگرێت بۆ کۆمپیوتەرەکەت
- [ ] Commit ـەکانت بار دەکات بۆ GitHub
- [ ] Branch ـێکی نوێ دروست دەکات
Why: Clone کردن کۆپییەکی ناوخۆیی دروست دەکات کە دەتوانیت کاری لەسەر بکەیت. ڕیپۆزیتۆرییەک تەنها یەک جار clone دەکەیت.

Q: هەنگاوە ڕۆژانەکان دوای دەستکاریکردنی فایلێک بە ڕیز دابنێ.
- [ ] `git push`، پاشان `git add`، پاشان `git commit`
- [x] `git add`، پاشان `git commit`، پاشان `git push`
- [ ] `git commit`، پاشان `git push`، پاشان `git add`
Why: گۆڕانکارییەکان stage بکە، وەک commit پاشەکەوتیان بکە، پاشان commit ـەکە بنێرە بۆ GitHub.

Q: کام فایل بە Git دەڵێت کام فایلانە پشتگوێ بخات؟
- [ ] `README.md`
- [ ] `ignore.txt`
- [x] `.gitignore`
Why: Git فایلی `.gitignore` دەخوێنێتەوە و هەر فایل یان فۆڵدەرێک کە لەگەڵ نموونەکانی ناویدا بگونجێت تێدەپەڕێنێت.
:::
