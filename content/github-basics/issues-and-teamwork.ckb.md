کۆد تەنها بەشێکی پڕۆژەیە. هەروەها پێویستە بزانیت دواتر چی بکەیت، چی تێکچووە، و کێ چی دەکات. لە GitHub دا ئەمە لە **issue** ـەکاندا ڕوودەدات.

## Issue چییە؟

Issue وەک کارتێکی کارەکانە کە بە ڕیپۆزیتۆرییەکەتەوە لکاوە. بۆ ئەمانە بەکاری بهێنە:

- هەڵەیەک (bug): *بەستەری پەیوەندی دەچێتە پەڕەی هەڵە*
- ئەرکێک: *گەلەرییەکی وێنە زیاد بکە*
- بیرۆکە یان پرسیارێک: *باکگراوندێکی تاریک بەکاربهێنین؟*

## دروستکردنی issue

1. تابی **Issues** ـی ڕیپۆزیتۆرییەکەت بکەرەوە.
2. کلیک لە **New issue** بکە.
3. ناونیشانێکی ڕوون و وەسفێک بنووسە. ڕوونی بکەرەوە چی هەڵەیە یان چی پێویستە، و چۆن دەزانیت تەواو بووە.
4. Issue ـەکە دروست بکە.

GitHub ژمارەیەک دەدات بە هەر issue ـێک، وەک `#1`. Issue ـەکان بە Markdown دەنووسرێن، بۆیە دەتوانیت لیستی پشکنین (checklist) زیاد بکەیت:

```markdown
To finish the gallery:
- [ ] Choose 6 photos
- [ ] Resize them
- [ ] Add captions
```

هەر `- [ ]` ـێک دەبێت بە چوارگۆشەیەک کە دەتوانیت نیشانەی بکەیت.

لە لای تەنیشتی issue ـێکدا دەتوانیت ئەمانە دیاری بکەیت:

- **Assignees**: کێ کاری لەسەر دەکات
- **Labels**: نیشانەی وەک `bug`، `enhancement` یان `good first issue`

## داخستنی issue بە pull request

کاتێک pull request ـێک issue ـێک چارەسەر دەکات، ئەمە لە وەسفی pull request ـەکەدا بنووسە:

```text
Closes #1
```

کاتێک pull request ـەکە merge دەکرێت، GitHub خۆکارانە issue ـی #1 دادەخات و هەردووکیان بە یەکەوە دەبەستێتەوە. هەر کەسێک دواتر دەتوانێت ببینێت کام گۆڕانکاری کام کێشەی چارەسەر کرد.

## قسەکردن لەگەڵ یەکتر

- لێدوان لەسەر issue و pull request ـەکان دابنێ بۆ گفتوگۆکردن لەسەریان.
- `@` بنووسە و لە دوایدا ناوی بەکارهێنەرێک، وەک `@sara-codes`، بۆ ئاماژەدان بە کەسێک. ئاگادارکردنەوەیەک وەردەگرێت.
- میهرەبان و ورد بە. "دێڕی 12 بەستەری `contact.htm` ـە بەڵام فایلەکە `contact.html` ـە" زۆر بەسوودترە لە "بەستەرەکە تێکچووە".

## بانگهێشتکردنی هاوتیم

بۆ ئەوەی ڕێگە بە هاوپۆلێکت بدەیت commit بکات بۆ ڕیپۆزیتۆرییەکەت:

1. بڕۆ بۆ **Settings** ـی ڕیپۆزیتۆرییەکە، پاشان **Collaborators**.
2. کلیک لە **Add people** بکە و ناوی بەکارهێنەرەکەی بنووسە.
3. بانگهێشتنامەیەکی بۆ دەچێت کە قبوڵی بکات.

## بەشداریکردن لە پڕۆژەکانی کەسانی تر

ناتوانیت commit بکەیت بۆ ڕیپۆزیتۆرییەک کە دەستت پێی ناگات، بەڵام دەتوانیت **fork** ـی بکەیت. Fork کۆپییەکی تایبەت بە خۆتە لە ڕیپۆزیتۆریی کەسێکی تر، لە هەژمارەکەی خۆتدا. لە fork ـەکەتدا گۆڕانکاری دەکەیت، پاشان pull request ـێک دەکەیتەوە بۆ پێشنیارکردنیان بە پڕۆژە ئەسڵییەکە. خەڵک لە سەرانسەری جیهان بەم شێوەیە بەشداری لە نەرمەکاڵای سەرچاوە-کراوەدا (open source) دەکەن.

:::quiz
Q: هاوپۆلەکەت هەڵەیەکی لە ماڵپەڕەکەتدا دۆزیوەتەوە. لە کوێ ڕاپۆرتی بکات؟
- [ ] لە پەیامێکی commit دا
- [x] لە issue ـێکی نوێدا
- [ ] بە دەستکاریکردنی ڕاستەوخۆی `main`
Why: Issue ـەکان بۆ بەدواداچوونی هەڵە، ئەرک و بیرۆکەن. گفتوگۆکە لە یەک شوێندا و بە پڕۆژەکەوە لکاو دەهێڵنەوە.

Q: ئەگەر وەسفی pull request ـێکی merge کراو بڵێت `Closes #4`، چی ڕوودەدات؟
- [x] Issue ـی #4 خۆکارانە دادەخرێت
- [ ] Pull request ـی #4 دەسڕدرێتەوە
- [ ] ڕیپۆزیتۆرییەکە لە گۆڕانکاریی نوێ دادەخرێت
Why: GitHub وشەی کلیلی وەک "Closes" دەناسێتەوە و کاتێک pull request ـەکە merge دەکرێت، issue ـە بەستراوەکە دادەخات.

Q: Fork چییە؟
- [ ] Branch ـێک لەناو ڕیپۆزیتۆرییەکەی خۆتدا
- [x] کۆپییەکی تایبەت بە خۆت لە ڕیپۆزیتۆریی کەسێکی تر
- [ ] Merge ـێک کە هەڵە چووە
Why: Fork کردن ڕیپۆزیتۆریی کەسێکی تر کۆپی دەکات بۆ هەژمارەکەت تا بتوانیت بیگۆڕیت و بە pull request گۆڕانکارییەکانت پێشنیار بکەیت.
:::
