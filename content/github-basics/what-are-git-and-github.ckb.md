ئایا هەرگیز فایلت بەم شێوەیە پاشەکەوت کردووە: `essay.docx`، `essay_v2.docx`، `essay_final.docx` و `essay_final_REALLY_final.docx`؟ پرۆگرامسازانیش هەمان کێشەیان هەبوو، بەڵام بە سەدان فایل و دەیان کەس. Git و GitHub ئەم کێشەیە چارەسەر دەکەن.

## Git: ئامێرێکی گەشتی کات بۆ پڕۆژەکەت

**Git** بەرنامەیەکە کە گۆڕانکارییەکانی ناو فایلەکانی فۆڵدەرێک تۆمار دەکات. هەر جارێک دەگەیتە خاڵێکی باش، **وێنەیەکی خێرا** (snapshot) لە هەموو پڕۆژەکە پاشەکەوت دەکەیت، کە پێی دەوترێت **commit**. هەر commit ـێک ئەمانە تۆمار دەکات:

- چی گۆڕاوە، دێڕ بە دێڕ
- کێ گۆڕیویەتی
- کەی
- پەیامێکی کورت کە ڕوونی دەکاتەوە بۆچی

دەتوانیت سەیری هەر commit ـێک بکەیتەوە، وەشانەکان بەراورد بکەیت و هەڵەکان هەڵبوەشێنیتەوە، بەبێ ئەوەی جارێکی تر کۆپی `_v2` دروست بکەیت.

## GitHub: ئەو شوێنەی پڕۆژەکان لەسەر ئینتەرنێت دەژین

**GitHub** ماڵپەڕێکە کە پڕۆژەکانی Git لەسەر ئینتەرنێت هەڵدەگرێت و ئامرازی کارکردن لەگەڵ کەسانی تری بۆ زیاد دەکات. لە GitHub دەتوانیت:

- پاشەکەوتی یەدەگی (backup) ـی پڕۆژەکانت بکەیت و لە هەر کۆمپیوتەرێکەوە دەستت پێیان بگات
- لەسەر هەمان پڕۆژە لەگەڵ هاوپۆلەکانت کار بکەیت بەبێ ئەوەی کاری یەکتر بسڕنەوە
- گفتوگۆ لەسەر بیرۆکەکان بکەیت و ئەرکەکان بەدوا بکەویت
- کارەکانت نیشانی مامۆستا، زانکۆ و خاوەنکارانی داهاتوو بدەیت
- ماڵپەڕ بە خۆڕایی بڵاو بکەیتەوە (ئەوە GitHub Pages ـە)

> بەم شێوەیە بیری لێ بکەرەوە: **Git کامێراکەیە** کە وێنەی کارەکەت دەگرێت. **GitHub ئەلبومە هاوبەشە ئۆنلاینەکەیە** کە ئەو وێنانەی تێدا هەڵدەگیرێن، و کەسانی تر دەتوانن ببینن و هی خۆیانی بۆ زیاد بکەن.

دەتوانیت Git بەبێ GitHub بەکاربهێنیت، بەڵام GitHub لەسەر Git دروست کراوە. لەم کۆرسەدا لە ماڵپەڕی GitHub ـەوە دەست پێ دەکەیت، کە Git لە پشتەوە کار دەکات، و دواتر Git ڕاستەوخۆ لەسەر کۆمپیوتەرەکەت بەکاردەهێنیت.

## ئەو وشانەی زۆر دەیانبیستیت

| وشە | مانا |
| --- | --- |
| Repository (ڕیپۆزیتۆری) | فۆڵدەرێکی پڕۆژە کە Git بەدوای دەکەوێت، لەگەڵ هەموو مێژووەکەی |
| Commit | وێنەیەکی پاشەکەوتکراوی گۆڕانکارییەکانت، لەگەڵ پەیامێک |
| Branch (لق) | ڕێڕەوێکی جیای کار کە دەتوانیت بە سەلامەتی گۆڕانکاری تێدا تاقی بکەیتەوە |
| Pull request | داواکارییەک بۆ هێنانی گۆڕانکاری لە branch ـێکەوە بۆ یەکێکی تر، تا کەسانی تر سەرەتا پێیدا بچنەوە |
| Merge (تێکەڵکردن) | تێکەڵکردنی گۆڕانکارییەکانی branch ـێک لەگەڵ یەکێکی تر |
| Clone | داگرتنی کۆپییەکی ڕیپۆزیتۆری بۆ کۆمپیوتەرەکەت |
| Push / pull | ناردنی commit ـەکانت بۆ GitHub / هێنانەخوارەوەی commit ـە نوێیەکان لێیەوە |

ئێستا هەوڵ مەدە ئەمانە لەبەر بکەیت. هەر وشەیەک وانەیەکی کرداریی تایبەت بە خۆی هەیە.
