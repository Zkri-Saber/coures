لەم وانەیەدا هەژمارێکی GitHub و یەکەم ڕیپۆزیتۆریت دروست دەکەیت. هەموو شتێک لە وێبگەڕدا ڕوودەدات؛ پێویست ناکات هیچ شتێک دابمەزرێنیت.

## هەژمارەکەت دروست بکە

1. بڕۆ بۆ [github.com](https://github.com) و کلیک لە **Sign up** بکە.
2. ئیمەیڵەکەت، وشەیەکی نهێنیی بەهێز و **ناوی بەکارهێنەر** (username) بنووسە.
3. کاتێک GitHub کۆدێکت بۆ دەنێرێت، ناونیشانی ئیمەیڵەکەت پشتڕاست بکەرەوە.

هەڵبژاردنی ناوی بەکارهێنەر:

- لە هەموو بەستەرەکانتدا دەردەکەوێت، وەک `github.com/your-username`، بۆیە کورت و ئاسانی بخوێنرێتەوە با بێت.
- شتێک هەڵبژێرە کە پێت خۆش بێت نیشانی مامۆستا یان خاوەنکارێکی بدەیت. `sara-codes` باشترە لە `xX_destroyer_Xx`.
- ساڵی لەدایکبوون، ژمارەی تەلەفۆن یان وردەکاریی کەسیی تری تێدا مەنووسە.

> بۆ ئەوەی هەژماری GitHub ـت هەبێت، دەبێت لانیکەم تەمەنت 13 ساڵ بێت. هەندێک وڵات تەمەنێکی زیاتر داوا دەکەن.

لەوانەیە GitHub داوات لێ بکات **ناسینەوەی دوو-هەنگاوی** (two-factor authentication) چالاک بکەیت (کۆدێک لە بەرنامەیەکی سەر مۆبایلەکەتەوە هەر جارێک دەچیتە ژوورەوە). قبوڵی بکە: هەژمارەکەت دەپارێزێت تەنانەت ئەگەر کەسێک وشەی نهێنییەکەشت بزانێت.

## ڕیپۆزیتۆرییەک دروست بکە

1. لە گۆشەی سەرەوەی ڕاستی هەر پەڕەیەکی GitHub، کلیک لە دوگمەی **+** بکە، پاشان **New repository**.
2. لە **Repository name** دا، بنووسە `hello-world`.
3. لە **Description** دا یەک ڕستە بنووسە، وەک *یەکەم ڕیپۆزیتۆریم، بۆ ڕاهێنان لەسەر GitHub*.
4. **Public** هەڵبژێرە. هەموو کەسێک دەتوانێت ڕیپۆزیتۆرییە گشتییەکان ببینێت؛ تەنها تۆ (و ئەو کەسانەی بانگهێشتیان دەکەیت) دەتوانن تایبەتەکان ببینن.
5. **Add a README file** چالاک بکە.
6. کلیک لە **Create repository** بکە.

## گەشتێک بە ناو ڕیپۆزیتۆرییەکەتدا

پەڕەی ڕیپۆزیتۆرییە نوێیەکەت چەند بەشێکی سەرەکیی هەیە:

- **لیستی فایلەکان** هەموو فایل و فۆڵدەرێک پیشان دەدات. ئێستا تەنها `README.md` هەیە.
- **README** لە خوار لیستی فایلەکانەوە پیشان دەدرێت. پەڕەی پێشەوەی پڕۆژەکەتە: یەکەم شت کە سەردانکەران دەیخوێننەوە.
- **تابەکان** لە سەرەوە (**Code**، **Issues**، **Pull requests**، **Settings** و هی تر) ئەو شوێنانەن کە لە وانەکانی داهاتوودا کاریان تێدا دەکەیت.
- **لیستی branch** کە ناوی `main` ـی لەسەرە، پیشان دەدات سەیری کام وەشانی پڕۆژەکە دەکەیت.
- **ژمارەی commit ـەکان** لە نزیک لیستی فایلەکانەوە (بۆ نموونە *1 Commit*) هەموو مێژووەکە دەکاتەوە.

## فایلەکانی README بە Markdown دەنووسرێن

`README.md` بە `.md` کۆتایی دێت چونکە بە **Markdown** نووسراوە: دەقی سادە لەگەڵ چەند نیشانەیەک بۆ شێوەدان.

```markdown
# Big heading
## Smaller heading

Some **bold** text and some *italic* text.

- A bullet point
- Another one

[A link](https://github.com)
```

لە وانەی داهاتوودا README ـەکەت دەستکاری دەکەیت. دەتوانیت بە کوردیش بینووسیت.

:::quiz
Q: کێ دەتوانێت ڕیپۆزیتۆرییەکی گشتی (public) ببینێت؟
- [x] هەموو کەسێک لەسەر ئینتەرنێت
- [ ] تەنها تۆ
- [ ] تەنها ئەو کەسانەی بانگهێشتیان دەکەیت
Why: ڕیپۆزیتۆرییە گشتییەکان بۆ هەمووان دیارن. تایبەتەکان تەنها بۆ تۆ و ئەوانەی بانگهێشتیان دەکەیت دیارن، بۆیە هەرگیز زانیاریی کەسی مەخەرە ناو ڕیپۆزیتۆرییەکی گشتییەوە.

Q: فایلی README بۆ چییە؟
- [ ] وشەی نهێنیی GitHub ـەکەت هەڵدەگرێت
- [x] ڕوونی دەکاتەوە پڕۆژەکە چییە؛ GitHub لەسەر پەڕەی پێشەوەی ڕیپۆزیتۆرییەکە پیشانی دەدات
- [ ] لیستی هەموو ئەو commit ـانەیە کە کراون
Why: README یەکەم شتە کە سەردانکەران دەیخوێننەوە، بۆیە دەبێت ڕوونی بکاتەوە پڕۆژەکە چییە و چۆن بەکاردەهێنرێت.
:::
