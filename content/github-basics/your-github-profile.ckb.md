پرۆفایلی GitHub ـەکەت، لە `github.com/your-username`، پۆرتفۆلیۆیەکە بۆ هەموو ئەو شتانەی دروستیان دەکەیت. مامۆستا، زانکۆ و خاوەنکاران زۆرجار سەیری دەکەن. با هی خۆت جوان بکەین.

## زیادکردنی README ـی پرۆفایل

GitHub تایبەتمەندییەکی شاراوەی هەیە: ئەگەر ڕیپۆزیتۆرییەک دروست بکەیت کە **ناوەکەی ڕێک وەک ناوی بەکارهێنەرەکەت بێت**، README ـەکەی لە سەرەوەی پرۆفایلەکەت دەردەکەوێت.

1. کلیک لە **+** بکە، پاشان **New repository**.
2. هەمان ناوی بەکارهێنەرەکەتی لێ بنێ. بۆ نموونە، ئەگەر تۆ `sara-codes` بیت، ناوی بنێ `sara-codes`. GitHub پەیامێک پیشان دەدات کە دەڵێت ئەمە ڕیپۆزیتۆرییەکی تایبەتە.
3. بیکە بە **Public** و **Add a README file** چالاک بکە.
4. کلیک لە **Create repository** بکە، پاشان README ـەکە دەستکاری بکە.

بیرۆکە بۆ ئەوەی چی بنووسیت:

```markdown
# Hi, I'm Sara 👋

I'm a Grade 10 student learning web development and Python.

## What I'm working on
- An about-me website ([see it live](https://sara-codes.github.io/about-me/))
- A number-guessing game in Python

## What I'm learning next
- JavaScript
- Making games with Pygame
```

دەتوانیت بە کوردی، ئینگلیزی یان هەردووکیان بینووسیت. کورت و دۆستانە و دەربارەی کارەکانت با بێت. ناونیشانی ماڵ، ژمارەی تەلەفۆن یان خشتەی قوتابخانەکەت مەنووسە.

## باشترین کارەکانت بچەسپێنە

لە پەڕەی پرۆفایلەکەتدا، کلیک لە **Customize your pins** بکە و تا شەش ڕیپۆزیتۆری هەڵبژێرە بۆ پیشاندان. ئەو پڕۆژە تەواوکراوانە هەڵبژێرە کە شانازییان پێوە دەکەیت، نەک ڕیپۆزیتۆریی بەتاڵی ڕاهێنان.

## هەر پڕۆژەیەک ئاسانی تێبگەیشتن بێت

بۆ هەر ڕیپۆزیتۆرییەک کە دەیچەسپێنیت:

- **وەسفێکی** یەک ڕستەیی زیاد بکە (ئایکۆنی چەرخ لە تەنیشت *About* لەسەر پەڕەی ڕیپۆزیتۆرییەکە).
- README ـێک بنووسە کە ڕوونی بکاتەوە **چییە**، **چۆن بەکاردەهێنرێت**، و ئەگەر شتێکی بینراوە وێنەیەکی شاشەی تێدا بێت.
- ئەگەر ماڵپەڕێکە لەسەر GitHub Pages، بەستەرەکەی لە بەشی *About* دا زیاد بکە.

## گرافی بەشدارییەکانت

پرۆفایلەکەت تۆڕێک لە چوارگۆشە پیشان دەدات، یەکێک بۆ هەر ڕۆژێکی ساڵ. چوارگۆشەیەک لەو ڕۆژانەدا سەوز دەبێت کە commit دەکەیت. ڕێگایەکی خۆشە بۆ بینینی پێشکەوتنەکەت، بەڵام تەنها بۆ سەوزکردنی چوارگۆشەکان کار مەکە: یەک commit ـی بەمانا لە دە commit ـی بچووک بەنرخترە.

## کۆرسەکەت تەواو کرد

ئێستا دەتوانیت ڕیپۆزیتۆری دروست بکەیت، بە commit کارەکانت پاشەکەوت بکەیت، بە branch و pull request و issue هاوکاری بکەیت، و Git لەسەر کۆمپیوتەرەکەت بەکاربهێنیت. پڕۆژەی کۆتاییت هەموو ئەمانە پێکەوە دەبەستێت.

:::quiz
Q: دەبێت ناوی ڕیپۆزیتۆرییەک چی بێت بۆ ئەوەی README ـەکەی لەسەر پرۆفایلەکەت دەربکەوێت؟
- [ ] `profile`
- [ ] `README`
- [x] ڕێک وەک ناوی بەکارهێنەری GitHub ـەکەت
Why: GitHub ڕیپۆزیتۆرییەکی گشتی کە بە ناوی بەکارهێنەرەکەت ناونرابێت وەک README ـی پرۆفایلەکەت مامەڵە دەکات.

Q: کام ڕیپۆزیتۆرییانە باشترینن بۆ چەسپاندن لەسەر پرۆفایلەکەت؟
- [ ] ئەوانەی زۆرترین commit یان هەیە
- [x] پڕۆژە تەواوکراوەکان کە شانازییان پێوە دەکەیت، لەگەڵ README ـی ڕوون
- [ ] هەموو ڕیپۆزیتۆرییەک کە هەرگیز دروستت کردووە
Why: چەسپاندنەکان پیشانگاکەتن. چەند پڕۆژەیەکی تەواو و ڕوونکراوە کاریگەرییەکی زۆر باشتر دروست دەکەن لە زۆرێکی بەتاڵ.
:::
