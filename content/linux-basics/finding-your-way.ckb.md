لە لینوکسدا، هەموو شتێک لە یەک دارەی گەورەی فۆڵدەرەکاندا دەژی (خەڵکی لینوکس زۆرجار دەڵێن **directory**). هیچ پیتێکی وەک `C:` نییە. دارەکە لە سەرەوەترین خاڵەوە دەست پێ دەکات، کە پێی دەوترێت **ڕەگ** (root) و بە یەک `/` دەنووسرێت.

```text
/                  ← the root: everything starts here
├── home/
│   └── sara/      ← your home folder (~)
├── etc/           ← system settings
├── usr/
│   └── bin/       ← most programs live here
└── tmp/           ← temporary files
```

## لە کوێم؟

```bash
pwd
```

`pwd` (print working directory) ئەو فۆڵدەرە پیشان دەدات کە ئێستا تێیدایت، بۆ نموونە `/home/sara`.

## چی لێرەیە؟

```bash
ls
```

`ls` ئەوەی لە فۆڵدەری ئێستادایە لیست دەکات. دوو هەڵبژاردەی بەسوود:

```bash
ls -l      # long list: sizes, dates and permissions
ls -a      # show hidden files too
```

ئەو فایلانەی ناوەکانیان بە خاڵ دەست پێ دەکات، وەک `.bashrc`، **شاراوەن**. زۆرجار فایلی ڕێکخستنن. دەتوانیت هەڵبژاردەکان تێکەڵ بکەیت: `ls -la`.

> ئەگەر فۆڵدەری ماڵەوەت بەتاڵ دەردەکەوێت، لەسەر سیستەمێکی نوێ ئەمە ئاساییە. لە وانەی داهاتوودا فایل و فۆڵدەر دروست دەکەیت.

## هاتوچۆکردن

`cd` (change directory) دەتبات بۆ فۆڵدەرێکی تر:

```bash
cd /etc        # go to the etc folder
ls             # see what's in it
cd ..          # go up one level (to /)
cd ~           # go back home
```

هەندێک کورتەڕێ:

| دەینووسیت | مانای |
| --- | --- |
| `~` | فۆڵدەری ماڵەوەت. `cd` بە تەنهاش دەتباتەوە ماڵەوە |
| `..` | فۆڵدەری یەک ئاست بەرزتر |
| `.` | فۆڵدەری ئێستا |
| `/` | ڕەگی هەموو دارەکە |
| `cd -` | بگەڕێرەوە بۆ ئەو فۆڵدەرەی پێشتر تێیدا بوویت |

## ڕێڕەوی تەواو و ڕێژەیی

**ڕێڕەو** (path) دەڵێت فایلێک یان فۆڵدەرێک لە کوێیە.

- **ڕێڕەوی تەواو** (absolute path) بە `/` دەست پێ دەکات و لە هەر شوێنێکەوە کار دەکات: `/home/sara/projects`
- **ڕێڕەوی ڕێژەیی** (relative path) لەو شوێنەوە دەست پێ دەکات کە ئێستا تێیدایت: ئەگەر لە `/home/sara` دابیت، ئەوا `projects` هەمان شت دەگەیەنێت.

وەک ڕێنیشاندان وایە: "کتێبخانەکەی ژمارە 12ی شەقامی سەرەکی" (تەواو) یان "دوو دەرگا لێرەوە" (ڕێژەیی).

## ناو بە بۆشاییەوە

تێرمیناڵ بۆشایی بەکاردەهێنێت بۆ جیاکردنەوەی بەشەکانی فەرمانێک، بۆیە فۆڵدەرێک بە ناوی `My Files` سەری لێ دەشێوێنێت. ناوەکە بخەرە ناو نیشانەی وتەوە:

```bash
cd "My Files"
```

باشتر وایە، لە ناودا بۆشایی بەکار مەهێنە. لە جیاتی ئەوە هێڵی ناوەڕاست یان ژێرەوە بەکاربهێنە: `my-files`.

> لەسەر WSL، دیسکەکانی ویندۆزت لەناو لینوکسیشدان: `C:` لە `/mnt/c` دایە. `ls /mnt/c/Users` تاقی بکەرەوە.

:::quiz
Q: کام فەرمان ئەو فۆڵدەرە پیشان دەدات کە ئێستا تێیدایت؟
- [x] `pwd`
- [ ] `ls`
- [ ] `cd`
Why: `pwd` فۆڵدەری کارکردنی ئێستا پیشان دەدات. `ls` ناوەڕۆکەکەی لیست دەکات، و `cd` دەتبات بۆ شوێنێکی تر.

Q: لە `/home/sara/projects` دایت. `cd ..` دەتبات بۆ کوێ؟
- [ ] `/`
- [x] `/home/sara`
- [ ] `/home/sara/projects/..`
Why: `..` واتە یەک ئاست بەرزتر، بۆیە لە `projects` ـەوە دەچیت بۆ فۆڵدەری باوانی، `/home/sara`.

Q: کامیان ڕێڕەوێکی تەواوە؟
- [ ] `projects/website`
- [ ] `../photos`
- [x] `/home/sara/photos`
Why: ڕێڕەوە تەواوەکان بە `/`، واتە ڕەگ، دەست پێ دەکەن، بۆیە لە هەر شوێنێک بیت ئاماژە بە هەمان شوێن دەکەن.
:::
