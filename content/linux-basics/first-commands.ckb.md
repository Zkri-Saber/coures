تێرمیناڵەکەت بکەرەوە. **پرۆمپت** (prompt) دەبینیت، کە شتێکی وەک ئەمە دەردەکەوێت:

```text
sara@laptop:~$
```

| بەش | مانا |
| --- | --- |
| `sara` | ناوی بەکارهێنەرەکەت |
| `laptop` | ناوی کۆمپیوتەرەکە |
| `~` | ئەو فۆڵدەرەی تێیدایت (`~` واتە فۆڵدەری ماڵەوەت) |
| `$` | لینوکس ئامادەیە بۆ فەرمانێک |

## چەند فەرمانێک تاقی بکەرەوە

هەر یەکێکیان بنووسە و **Enter** دابگرە:

```bash
whoami
date
echo I am learning Linux
```

- `whoami` ناوی بەکارهێنەرەکەت پیشان دەدات.
- `date` بەروار و کات پیشان دەدات.
- `echo` هەرچییەک دوای خۆی بنووسیت دووبارەی دەکاتەوە.

کاتێک شاشەکە قەرەباڵغ بوو، بنووسە `clear` بۆ پاککردنەوەی.

## شێوەی فەرمانێک

زۆربەی فەرمانەکان هەمان نموونە پەیڕەو دەکەن:

```text
command  -options  arguments
   ls       -l      /home
```

- **فەرمان** (command) ئەوەیە چی بکرێت: `ls` فایلەکان لیست دەکات.
- **هەڵبژاردەکان** (options، یان flags) چۆنیەتیی کارکردنەکەی دەگۆڕن. زۆرجار بە `-` دەست پێ دەکەن. لێرەدا `-l` واتە "شێوەی درێژ، لەگەڵ وردەکاری".
- **ئارگومێنتەکان** ئەوەن کە کارەکەی لەسەر دەکرێت. لێرەدا `/home` ئەو فۆڵدەرەیە کە لیست دەکرێت.

لینوکس **جیاوازی لە نێوان پیتی گەورە و بچووکدا دەکات**: `ls` کار دەکات، بەڵام `LS` و `Ls` کار ناکەن.

## کورتەڕێی کیبۆرد کە کات دەپارێزن

| کلیل | چی دەکات |
| --- | --- |
| **تیری سەرەوە** | فەرمانە پێشووەکانت دەهێنێتەوە، تا دووبارە نەیاننووسیتەوە |
| **Tab** | تەواوکردنی خۆکار. چەند پیتی یەکەمی فەرمانێک یان ناوی فایلێک بنووسە و Tab دابگرە |
| **Ctrl + C** | ئەو فەرمانەی ئێستا کار دەکات ڕادەگرێت |
| **Ctrl + L** | شاشەکە پاک دەکاتەوە (هەمان `clear`) |

هەمیشە **Tab** بەکاربهێنە. خێراترە، و ڕێگری لە هەڵەی نووسین لە ناوی فایلی درێژدا دەکات.

بنووسە `history` تا لیستێکی ژمارەدار لە هەموو ئەو فەرمانانە ببینیت کە جێبەجێت کردوون.

## وەرگرتنی یارمەتی

نزیکەی هەموو فەرمانێک ڕێبەرێکی ناوخۆیی هەیە:

```bash
man ls
```

تیرەکان بەکاربهێنە بۆ هاتوچۆ و **q** دابگرە بۆ دەرچوون. بۆ پوختەیەکی کورتتر، زۆرێک لە فەرمانەکان `--help` قبوڵ دەکەن:

```bash
ls --help
```

## کاتێک هەڵە دەچێت

ئەگەر `command not found` ببینیت، ڕێنووس و پیتە گەورەکان بپشکنە. ئەگەر فەرمانێک گیرابێت، **Ctrl + C** دابگرە. بە فەرمانەکانی ئەم وانەیە ناتوانیت هیچ شتێک تێک بدەیت، بۆیە بە ئازادی تاقیکاری بکە.

:::quiz
Q: لە پرۆمپتی `sara@laptop:~$` دا، `~` مانای چییە؟
- [ ] فەرمانەکە هێشتا کار دەکات
- [x] لە فۆڵدەری ماڵەوەتدایت
- [ ] تۆ بەڕێوەبەریت
Why: `~` ناوی کورتی فۆڵدەری ماڵەوەتە، کە فایلە کەسییەکانتی تێدایە.

Q: لە `ls -l /home` دا، `-l` چییە؟
- [ ] فەرمانەکە
- [x] هەڵبژاردەیەک کە چۆنیەتیی کارکردنی فەرمانەکە دەگۆڕێت
- [ ] ئەو فۆڵدەرەی لیست دەکرێت
Why: هەڵبژاردەکان زۆرجار بە `-` دەست پێ دەکەن. `-l` بە `ls` دەڵێت وردەکاری لە لیستێکی درێژدا پیشان بدات.

Q: فەرمانێک زۆر دەخایەنێت و دەتەوێت ڕایبگریت. چی دادەگریت؟
- [ ] Tab
- [ ] تیری سەرەوە
- [x] Ctrl + C
Why: Ctrl + C ئەو فەرمانەی کار دەکات ڕادەگرێت و پرۆمپتەکەت بۆ دەگەڕێنێتەوە.
:::
