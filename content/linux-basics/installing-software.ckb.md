لەسەر مۆبایلەکەت بەرنامە لە فرۆشگای بەرنامەکان (app store) دادەمەزرێنیت. لینوکس زۆر پێش مۆبایلەکان هەمان بیرۆکەی هەبوو: **بەڕێوەبەری پاکێج** (package manager) نەرمەکاڵا لە کۆگا متمانەپێکراوەکەی دیسترۆکەتەوە (کە پێی دەوترێت **ڕیپۆزیتۆری**) دادەگرێت، دایدەمەزرێنێت، و نوێی دەهێڵێتەوە.

لەسەر Ubuntu و Debian، بەڕێوەبەری پاکێج ناوی `apt` ـە.

## سەرەتا لیستەکە نوێ بکەرەوە

```bash
sudo apt update
```

ئەمە هیچ شتێک دانامەزرێنێت. دوایین لیستی نەرمەکاڵا و وەشانە بەردەستەکان دادەگرێت، تا `apt` بزانێت چی هەیە. پێش دامەزراندن جێبەجێی بکە.

## دامەزراندنی شتێک

با دوو ئامرازی بچووک و خۆش دابمەزرێنین:

```bash
sudo apt install tree figlet
```

`apt` پیشان دەدات چی دادەمەزرێنێت و داوات لێ دەکات پشتڕاستی بکەیتەوە. `y` بنووسە و Enter دابگرە. پاشان تاقییان بکەرەوە:

```bash
tree ~          # shows your home folder as a tree
figlet Hello!   # prints Hello! in giant letters
```

## فەرمانە بەسوودەکانی تری apt

| فەرمان | چی دەکات |
| --- | --- |
| `apt search weather` | گەڕان بەدوای پاکێجەکانی پەیوەست بە "weather" (کەشوهەوا) |
| `apt show tree` | پیشاندانی وردەکاریی پاکێجێک |
| `sudo apt upgrade` | نوێکردنەوەی **هەموو** نەرمەکاڵا دامەزراوەکانت |
| `sudo apt remove figlet` | لابردنی پاکێجێک |

خوویەکی باش: هەر یەک یان دوو هەفتە جارێک `sudo apt update` و پاشان `sudo apt upgrade` جێبەجێ بکە بۆ وەرگرتنی چاککردنەوە ئەمنییەکان.

## بۆچی بەڕێوەبەری پاکێج باشترە لە داگرتن

- **سەلامەت:** پاکێجەکان لە ڕیپۆزیتۆریی دیسترۆکەتەوە دێن، کە تێیدا پشکنراون و واژۆ کراون.
- **ئاسان:** یەک فەرمان بەرنامەیەک و هەموو ئەو شتانەی پێویستییەتی بۆ کارکردن (*dependency* ـەکانی) دادەمەزرێنێت.
- **نوێ:** یەک فەرمان هەموو بەرنامەکان بە یەکجار نوێ دەکاتەوە.

## دیسترۆکانی تر و ماک

بیرۆکەکە لە هەموو شوێنێک هەمانە؛ تەنها ناوی فەرمانەکە دەگۆڕێت:

| سیستەم | فەرمانی دامەزراندن |
| --- | --- |
| Ubuntu، Debian، Linux Mint، WSL | `sudo apt install tree` |
| Fedora | `sudo dnf install tree` |
| Arch Linux | `sudo pacman -S tree` |
| ماک (دوای دامەزراندنی [Homebrew](https://brew.sh)) | `brew install tree` |

> تەنها لە ڕیپۆزیتۆریی دیسترۆکەتەوە یان سەرچاوەیەکی متمانەپێکراوەوە نەرمەکاڵا دابمەزرێنە. ئەگەر ماڵپەڕێک پێت بڵێت فەرمانێکی درێژ کە بە `sudo` یان `curl` دەست پێ دەکات دابنێیت، سەرەتا لە مامۆستاکەت بپرسە.

:::quiz
Q: `sudo apt update` چی دەکات؟
- [ ] هەموو بەرنامە بەردەستەکان دادەمەزرێنێت
- [x] دوایین لیستی پاکێجە بەردەستەکان دادەگرێت
- [ ] لینوکس بۆ وەشانێکی نوێ بەرز دەکاتەوە
Why: `update` لیستی ئەوەی بەردەستە نوێ دەکاتەوە. `upgrade` ئەو فەرمانەیە کە بەڕاستی نەرمەکاڵا دامەزراوەکانت نوێ دەکاتەوە.

Q: بۆچی پێویستت بە `sudo` هەیە لە پێش `apt install`؟
- [x] دامەزراندنی نەرمەکاڵا سیستەمەکە دەگۆڕێت، کە پێویستی بە هێزی بەڕێوەبەر هەیە
- [ ] هەموو فەرمانێکی لینوکس پێویستی بە `sudo` هەیە
- [ ] داگرتنەکە خێراتر دەکات
Why: دامەزراندنی نەرمەکاڵا دەنووسێتە ناو فۆڵدەرەکانی سیستەمەوە کە بەکارهێنەرە ئاساییەکان ناتوانن بیانگۆڕن.
:::
