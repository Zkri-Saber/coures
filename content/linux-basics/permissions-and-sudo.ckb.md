لینوکس بۆ ئەوە دیزاین کراوە کە چەندین کەس یەک کۆمپیوتەر بەکاربهێنن، بۆیە هەموو فایلێک **خاوەنێک** و یاسایەکی هەیە دەربارەی ئەوەی کێ دەتوانێت چی پێ بکات. ئەم یاسایانە پێیان دەوترێت **مۆڵەتەکان** (permissions).

## خوێندنەوەی مۆڵەتەکان

لە فۆڵدەرێکدا کە چەند فایلێکی تێدایە `ls -l` جێبەجێ بکە:

```text
-rw-r--r-- 1 sara sara  120 Nov 16 10:02 notes.txt
drwxr-xr-x 2 sara sara 4096 Nov 16 10:05 projects
```

یەکەم ستوون زنجیرەی مۆڵەتەکانە. بیکە بە چوار بەش:

```text
-    rw-    r--    r--
│     │      │      └── others (everyone else)
│     │      └───────── group
│     └──────────────── owner (sara)
└────────────────────── type: - for a file, d for a directory
```

هەر کۆمەڵەیەکی سێ پیتی دەڵێت چی ڕێگەپێدراوە:

| پیت | بۆ فایل | بۆ فۆڵدەر |
| --- | --- | --- |
| `r` خوێندنەوە (read) | کردنەوە و خوێندنەوەی | لیستکردنی ناوەڕۆکەکەی |
| `w` نووسین (write) | گۆڕینی | زیادکردن یان سڕینەوەی فایل تێیدا |
| `x` جێبەجێکردن (execute) | جێبەجێکردنی وەک بەرنامە | چوونە ناوی بە `cd` |
| `-` | ڕێگەپێنەدراو | ڕێگەپێنەدراو |

بۆیە `-rw-r--r--` واتە: خاوەنەکە دەتوانێت بیخوێنێتەوە و بینووسێت؛ هەموو کەسانی تر تەنها دەتوانن بیخوێننەوە.

## گۆڕینی مۆڵەتەکان بە chmod

`chmod` (change mode) مۆڵەتەکان دەگۆڕێت. باوترین بەکارهێنانی ئامادەکردنی سکریپتێکە بۆ جێبەجێکردن:

```bash
chmod +x myscript.sh
```

`+x` مۆڵەتی جێبەجێکردن زیاد دەکات؛ `-x` لای دەبات. دەتوانیت کەسانی دیاریکراو ئامانج بکەیت: `u` (بەکارهێنەر/خاوەن)، `g` (گرووپ)، `o` (ئەوانی تر):

```bash
chmod o-r notes.txt    # others can no longer read it
```

هەروەها ژمارەش دەبینیت، وەک `chmod 755`. هەر ژمارەیەک کۆی خوێندنەوە (4)، نووسین (2) و جێبەجێکردن (1) ـە، بۆ خاوەن، گرووپ و ئەوانی تر بەو ڕیزە. بۆیە `755` واتە `rwxr-xr-x`، و `644` واتە `rw-r--r--`.

## بەکارهێنەری باڵا: root

لینوکس هەژمارێکی بەهێزی هەیە بە ناوی **root**. دەتوانێت هەر شتێک بخوێنێتەوە، بگۆڕێت و بسڕێتەوە، لەوانەش ئەو فایلانەی سیستەمەکە کار پێ دەکەن. بەکارهێنەرە ئاساییەکان ناتوانن، کە سیستەمەکە لە هەڵەی ڕێکەوت و لە بەرنامە زیانبەخشەکان دەپارێزێت.

کاتێک پێویستت بە گۆڕانکاری لە سیستەمدا هەیە، وەک دامەزراندنی نەرمەکاڵا، `sudo` ("superuser do") بەکاردەهێنیت بۆ جێبەجێکردنی **یەک** فەرمان بە هێزی root:

```bash
sudo apt update
```

لینوکس داوای وشەی نهێنیی **خۆت** دەکات (ئەوەی کاتی ئامادەکردنی لینوکس دروستت کرد)، پاشان فەرمانەکە وەک root جێبەجێ دەکات.

> ڕێز لە `sudo` بگرە. هەرگیز فەرمانێکی `sudo` جێبەجێ مەکە کە تێی ناگەیت، بەتایبەتی ئەوەی لە ماڵپەڕێکی نەناسراوەوە کۆپی کراوە. یەک فەرمانی هەڵە دەتوانێت زیان بە سیستەمەکەت بگەیەنێت.

## "Permission denied"

ئەم هەڵەیە واتە هەوڵی شتێکت داوە کە بەکارهێنەرەکەت ڕێگەی پێ نەدراوە. لە خۆت بپرسە:

- ئایا فایلێکی سیستەمە؟ لەوانەیە پێویستت بە `sudo` بێت، بەڵام تەنها ئەگەر دڵنیا بیت.
- ئایا سکریپتێکە کە هەوڵی جێبەجێکردنی دەدەیت؟ لەوانەیە پێویستی بە `chmod +x` بێت.
- ئایا فایلی کەسێکی ترە؟ کەواتە دەستی لێ مەدە.

:::quiz
Q: فایلێک `-rwxr--r--` پیشان دەدات. خاوەنەکەی چی دەتوانێت پێی بکات؟
- [ ] تەنها بیخوێنێتەوە
- [ ] بیخوێنێتەوە و بینووسێت
- [x] بیخوێنێتەوە، بینووسێت و جێبەجێی بکات
Why: سێ پیتەکەی خاوەن `rwx` ن: خوێندنەوە، نووسین و جێبەجێکردن.

Q: `chmod +x hello.sh` چی دەکات؟
- [x] ڕێگەت پێ دەدات `hello.sh` وەک بەرنامەیەک جێبەجێ بکەیت
- [ ] `hello.sh` دەسڕێتەوە
- [ ] `hello.sh` دەشارێتەوە
Why: `+x` مۆڵەتی جێبەجێکردن زیاد دەکات، کە سکریپتێک پێش جێبەجێکردنی پێویستی پێیەتی.

Q: کەی دەبێت `sudo` بەکاربهێنیت؟
- [ ] بۆ هەموو فەرمانێک، بۆ دوورکەوتنەوە لە هەڵە
- [x] تەنها کاتێک فەرمانێک پێویستی بە هێزی بەڕێوەبەر هەیە و تێدەگەیت چی دەکات
- [ ] هەرگیز: تەنها بۆ هاکەرەکانە
Why: `sudo` کۆنترۆڵی تەواوی سیستەم دەدات بە فەرمانێک، بۆیە تەنها کاتی پێویست و تەنها بۆ ئەو فەرمانانە بەکاری بهێنە کە تێیان دەگەیت.
:::
