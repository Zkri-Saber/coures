ئێستا دەیان فەرمان دەزانیت. جادووی ڕاستەقینەی لینوکس پێکەوە بەستنیانە: ئامرازی بچووک کە هەر یەکێکیان کارێک بە باشی دەکات، پێکەوە بەستراون.

## Pipe: بەستنەوەی فەرمانەکان

نیشانەی **pipe** (بۆری) `|` دەرئەنجامی فەرمانێک دەنێرێت بۆ فەرمانی دواتر، لە جیاتی شاشە:

```bash
ls -l /etc | less
```

`ls` فۆڵدەرێکی درێژ لیست دەکات، و `less` ڕێگەت پێ دەدات بە ناو ئەنجامەکەدا بڕۆیت. نموونەی زیاتر:

```bash
ls /usr/bin | wc -l       # how many programs are in /usr/bin?
history | tail -n 10      # your last 10 commands
```

`wc -l` دێڕەکان دەژمێرێت، بۆیە نموونەی یەکەم ئەو بەرنامانە دەژمێرێت کە لەسەر سیستەمەکەت دامەزراون.

## grep: دۆزینەوەی دەق

`grep` بەدوای وشەیەک یان دەستەواژەیەکدا دەگەڕێت و تەنها ئەو دێڕانە پیشان دەدات کە دەگونجێن:

```bash
grep milk shopping.txt          # lines containing "milk"
grep -i milk shopping.txt       # ignore upper/lower case
grep -r "homework" ~/school     # search every file in a folder
history | grep cd               # every cd command you've typed
```

## find: دۆزینەوەی فایل

```bash
find ~ -name "*.txt"
```

ئەمە لە هەموو فۆڵدەری ماڵەوەتدا (`~`) بەدوای ئەو فایلانەدا دەگەڕێت کە ناوەکانیان بە `.txt` کۆتایی دێت.

## یەکەم سکریپتت

**سکریپت** (script) فایلێکی دەقە پڕ لە فەرمان کە یەک لە دوای یەک جێبەجێ دەکرێن. لە جیاتی ئەوەی هەموو ڕۆژێک هەمان فەرمانەکان بنووسیت، یەک جار دەیاننووسیت.

فایلەکە دروست بکە:

```bash
nano hello.sh
```

ئەمەی تێدا بنووسە:

```bash
#!/bin/bash
# My first script

echo "Hello, $USER!"
echo "Today is $(date +%A)."
echo "You are in: $(pwd)"
echo "Files here:"
ls
```

بە **Ctrl + O** و **Enter** پاشەکەوتی بکە، پاشان بە **Ctrl + X** دەربچۆ.

مانای هەمووی:

- `#!/bin/bash` لە دێڕی یەکەمدا بە لینوکس دەڵێت فایلەکە بە **bash** جێبەجێ بکات، ئەو شێڵەی تا ئێستا تێیدا دەتنووسی.
- ئەو دێڕانەی بە `#` دەست پێ دەکەن لێدوانن، تەنها بۆ مرۆڤن.
- `$USER` **گۆڕاوێکە** کە ناوی بەکارهێنەرەکەت هەڵدەگرێت.
- `$(...)` فەرمانێک جێبەجێ دەکات و ئەنجامەکەی دەخاتە ناو دەقەکەوە. `date +%A` ڕۆژی هەفتە دەدات.

دەتوانیت دەقی کوردیش لەناو `echo` دا بنووسیت، بۆ نموونە `echo "سڵاو، $USER!"`.

جێبەجێکردنی ڕێگەپێبدە و جێبەجێی بکە:

```bash
chmod +x hello.sh
./hello.sh
```

`./` واتە "ئەو فایلەی لەم فۆڵدەرەدایە". لینوکس لە فۆڵدەری ئێستادا بەدوای بەرنامەدا ناگەڕێت مەگەر خۆت بیڵێیت، کە دەتپارێزێت لە جێبەجێکردنی شتێک بە هەڵە.

## پرسیارکردن لە بەکارهێنەر

`read` چاوەڕێ دەکات بەکارهێنەر شتێک بنووسێت و لە گۆڕاوێکدا هەڵیدەگرێت:

```bash
#!/bin/bash
read -p "What's your name? " name
echo "Nice to meet you, $name!"
```

## دەستخۆش

لە یەکەم `echo` ـەوە گەیشتیتە نووسینی سکریپت. پڕۆژەی کۆتاییت، لە پەڕەی کۆرسەکەدا، داوات لێ دەکات ئەوەی فێری بوویت تێکەڵ بکەیت و سکریپتێکی تایبەت بە خۆت بنووسیت.

:::quiz
Q: نیشانەی `|` لە `history | grep cd` دا چی دەکات؟
- [ ] هەردوو فەرمانەکە لە یەک کاتدا بە جیا جێبەجێ دەکات
- [x] دەرئەنجامی `history` دەنێرێت بۆ ناو `grep`
- [ ] مێژووەکە لە فایلێکدا بە ناوی `grep` پاشەکەوت دەکات
Why: Pipe دەرئەنجامی فەرمانێک وەک داهاتوو (input) دەداتە فەرمانی دواتر.

Q: بۆچی لە جیاتی `hello.sh`، دەنووسیت `./hello.sh`؟
- [ ] خاڵەکە خێراتری دەکات
- [x] لینوکس لە فۆڵدەری ئێستادا بەدوای بەرنامەدا ناگەڕێت مەگەر پێی بڵێیت
- [ ] سکریپتەکان دەبێت هەمیشە بە خاڵ دەست پێ بکەن
Why: `./` ئاماژە بە فۆڵدەری ئێستا دەکات، بۆیە لینوکس دەزانێت مەبەستت کام فایلە.

Q: لە سکریپتێکدا، `$USER` چی لەخۆ دەگرێت؟
- [x] ناوی بەکارهێنەرەکەت
- [ ] وشەی USER
- [ ] وشەی نهێنییەکەت
Why: `$USER` گۆڕاوێکە کە لینوکس دەیکات بە ناوی ئەو بەکارهێنەرەی چووەتە ژوورەوە.
:::
