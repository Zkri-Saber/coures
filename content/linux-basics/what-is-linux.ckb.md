هەموو کۆمپیوتەرێک پێویستی بە **سیستەمی کارپێکردن** (operating system) هەیە: ئەو نەرمەکاڵایەی ڕەقەکاڵا بەڕێوە دەبات (شاشە، کیبۆرد، بیرگە، هەڵگرتن) و بەرنامەکانت کار پێ دەکات. لەوانەیە ویندۆز، ماک (macOS)، ئەندرۆید و iOS بناسیت. لینوکس یەکێکی ترە، و لە هەموو شوێنێکە، تەنانەت ئەگەر هەرگیز سەرنجت نەدابێتێ.

## مێژوویەکی کورت

لە ساڵی 1991، قوتابییەکی فینلەندی بە ناوی لینوس تۆرڤالدز (Linus Torvalds) وەک خولیایەک دەستی کرد بە نووسینی سیستەمێکی کارپێکردن و کۆدەکەی لەسەر ئینتەرنێت بڵاو کردەوە تا هەر کەسێک بەکاری بهێنێت و باشتری بکات. هەزاران کەس بەشدارییان کرد. ئەمڕۆ لینوکس لەلایەن گەشەپێدەرانەوە لە سەرانسەری جیهان دروست دەکرێت، و **بەخۆڕایی و سەرچاوە-کراوە** (open source) ـە: هەر کەسێک دەتوانێت بەکاری بهێنێت، کۆدەکەی بخوێنێتەوە، بیگۆڕێت و هاوبەشی بکات.

## ناوک و دیسترۆکان

بە وردی، *لینوکس* **ناوک** (kernel) ـە: ناوەندی سیستەمی کارپێکردن کە قسە لەگەڵ ڕەقەکاڵا دەکات. بۆ بەدەستهێنانی سیستەمێکی تەواو و بەکارهاتوو، ناوکەکە لەگەڵ ئامراز، ڕووکار و بەرنامەکان پاکێج دەکرێت. هەر پاکێجێک پێی دەوترێت **دیسترۆ** (distribution):

| دیسترۆ | بە چی ناسراوە |
| --- | --- |
| Ubuntu | بەناوبانگترینە بۆ سەرەتاییەکان؛ ئەوەی لەم کۆرسەدا بەکاری دەهێنین |
| Linux Mint | شێوە و هەستی زۆر لە ویندۆز دەچێت |
| Debian | زۆر جێگیرە؛ Ubuntu لەسەر ئەم دروست کراوە |
| Fedora | نەرمەکاڵای نوێ |
| Raspberry Pi OS | لەسەر کۆمپیوتەری بچووک و هەرزانی Raspberry Pi کار دەکات |

ئەو فەرمانانەی فێریان دەبیت لەسەر نزیکەی هەموویان کار دەکەن.

## لینوکس لە کوێ کار دەکات

- **ڕاژەکاری وێب و کڵاود:** زۆربەی ئەو ماڵپەڕانەی سەردانیان دەکەیت لەلایەن کۆمپیوتەرەکانی لینوکسەوە پێشکەش دەکرێن.
- **مۆبایل:** ئەندرۆید لەسەر ناوکی لینوکس دروست کراوە.
- **سوپەرکۆمپیوتەر:** لە ساڵی 2017 ەوە، هەموو 500 خێراترین سوپەرکۆمپیوتەری جیهان لینوکسیان بەکارهێناوە.
- **ئامێرە ڕۆژانەکان:** تەلەفزیۆنی زیرەک، ڕاوتەری Wi-Fi، ئۆتۆمبێل، کۆنسۆڵی یاری و Raspberry Pi.

## بۆچی هێڵی فەرمان فێر بین؟

لینوکس ڕووکاری پەنجەرە و ئایکۆنی هەیە، وەک هەر سیستەمێکی تر. بەڵام هێزی ڕاستەقینەی لە **هێڵی فەرمان** (command line) دایە (کە پێشی دەوترێت **تێرمیناڵ** یان **شێڵ**)، کە لەوێ ڕێنمایی دەنووسیت لە جیاتی کلیککردن.

- ڕاژەکارەکان زۆرجار هیچ شاشە یان ڕووکارێکیان نییە. هێڵی فەرمان تاکە ڕێگای چوونە ژوورەوەیە.
- یەک فەرمانی نووسراو دەتوانێت ئەو کارە بکات کە سەد کلیکی پێویستە، وەک ناوگۆڕینی 500 وێنە.
- ئامرازەکانی پرۆگرامسازی، Git و خزمەتگوزارییەکانی کڵاود هەموویان چاوەڕێ دەکەن بیزانیت.

کۆن دەردەکەوێت، بەڵام پیشەگەران هەموو ڕۆژێک بەکاری دەهێنن چونکە خێرا و وردە.
