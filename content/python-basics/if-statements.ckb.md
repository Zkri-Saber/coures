تا ئێستا هەموو دێڕێکی بەرنامەکانت هەموو جارێک کار دەکات. ڕستەی `if` ڕێگە بە بەرنامە دەدات هەڵبژێرێت چی بکات.

```python
temperature = 34

if temperature > 30:
    print("It's hot. Drink some water!")
```

دێڕە بۆشایی-دراوەکە (indented) تەنها کاتێک کار دەکات کە مەرجەکە `True` بێت.

## بۆشایی سەرەتای دێڕ (indentation) گرنگە

پایتۆن بۆشایی سەرەتای دێڕ (4 بۆشایی) بەکاردەهێنێت بۆ ئەوەی بزانێت کام دێڕانە سەر بە `if` ـەکەن. هەموو ئەوەی لە ژێریدا بە بۆشاییەوە نووسراوە بەشێکە لە هەمان بلۆک:

```python
if temperature > 30:
    print("It's hot.")
    print("Stay in the shade.")
print("This line always runs.")
```

دوو خاڵەکە `:` لە کۆتایی دێڕی `if` لەبیر مەکە.

## بەراوردکردنی بەهاکان

| نیشانە | مانا |
| --- | --- |
| `==` | یەکسانە بە |
| `!=` | یەکسان نییە بە |
| `>` / `<` | گەورەترە لە / بچووکترە لە |
| `>=` / `<=` | گەورەتر یان یەکسان / بچووکتر یان یەکسان |

سەرنجی `==` ی دووانە بدە. یەک `=` بەهایەک هەڵدەگرێت؛ `==` دوو بەها بەراورد دەکات.

## else و elif

`else` کاتێک کار دەکات کە مەرجەکە هەڵە (false) بێت. `elif` (کورتکراوەی "else if") مەرجێکی تر دەپشکنێت:

```python
score = int(input("Your test score: "))

if score >= 90:
    print("Excellent!")
elif score >= 70:
    print("Good work.")
elif score >= 50:
    print("You passed.")
else:
    print("Let's practise together.")
```

پایتۆن هەموو مەرجێک لە سەرەوە بۆ خوارەوە دەپشکنێت و **تەنها یەکەم یەکیان** کە ڕاست بێت جێبەجێ دەکات.

## پێکەوە بەستنی مەرجەکان

`and` و `or` و `not` بەکاربهێنە:

```python
if age >= 13 and age <= 19:
    print("You're a teenager.")
```
