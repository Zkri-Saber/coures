بەرنامەکان سەرنجڕاکێش دەبن کاتێک وەڵامی ئەو کەسە دەدەنەوە کە بەکاریان دەهێنێت. فەنکشنی `input` پرسیارێک دەکات و چاوەڕێی وەڵام دەکات.

```python
name = input("What's your name? ")
print("Nice to meet you, " + name + "!")
```

هەرچییەک بەکارهێنەر بینووسێت لە گۆڕاوی `name` دا هەڵدەگیرێت.

## وەرگرتن هەمیشە دەقە

`input` هەمیشە **دەق** (string) دەداتێ، تەنانەت ئەگەر بەکارهێنەر ژمارەیەکیش بنووسێت. ئەمە دەبێتە هۆی هەڵەیەکی ناسراو:

```python
age = input("How old are you? ")
print(age + 1)    # error!
```

پایتۆن ناتوانێت ژمارەی 1 بخاتە سەر دەق. سەرەتا وەڵامەکە بە `int()` بگۆڕە:

```python
age = int(input("How old are you? "))
print("Next year you'll be", age + 1)
```

ئەگەر چاوەڕێی ژمارەیەکی دەیی دەکەیت، لە جیاتی `int()`، `float()` بەکاربهێنە.

## پیشاندانی چەند شتێک

دەتوانیت چەند بەهایەک بدەیت بە `print` کە بە کۆما (,) جیا کرابنەوە. خۆی بۆشاییەکیان دەخاتە نێوانەوە:

```python
print("You are", age, "years old")
```

یان **f-string** بەکاربهێنە: پیتی `f` لە پێش نیشانەکانی وتە دابنێ و گۆڕاوەکان لەناو کەوانەی لوولدار `{ }` بنووسە.

```python
print(f"Hi {name}, next year you'll be {age + 1}.")
```

f-string پاکترین ڕێگایە بۆ تێکەڵکردنی دەق و بەها، و زۆربەی پرۆگرامسازانی پایتۆن بەکاری دەهێنن. دەتوانیت دەقی کوردیشی تێدا بنووسیت:

```python
print(f"سڵاو {name}، ساڵی داهاتوو تەمەنت دەبێت بە {age + 1}.")
```

## خۆت تاقی بکەرەوە

بەرنامەیەک بنووسە کە درێژی و پانیی ژوورێک بە مەتر بپرسێت، پاشان ڕووبەرەکەی پیشان بدات.

```python
length = float(input("Length in metres: "))
width = float(input("Width in metres: "))
print(f"The area is {length * width} square metres.")
```
