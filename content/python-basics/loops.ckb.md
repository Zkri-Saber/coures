**لووپ** (loop) بلۆکێک لە کۆد دووبارە دەکاتەوە. لە جیاتی ئەوەی دە جار `print` بنووسیت، یەک جار دەینووسیت و بە پایتۆن دەڵێیت چەند جار جێبەجێی بکات.

## لووپی for: دووبارەکردنەوە بە ژمارەیەکی دیاریکراو

```python
for i in range(5):
    print("Hello!")
```

ئەمە پێنج جار Hello! پیشان دەدات. `range(5)` ژمارەکانی 0، 1، 2، 3، 4 دەدات، و `i` یەک لە دوای یەک هەر یەکێکیان هەڵدەگرێت:

```python
for i in range(1, 6):
    print(i, "x 7 =", i * 7)
```

`range(1, 6)` لە 1 دەست پێ دەکات و **پێش** 6 دەوەستێت، بۆیە ئەمە خشتەی لێدانی 7 لە 1 تا 5 پیشان دەدات.

## لووپ بەسەر لیستێکدا

**لیست** (list) چەند بەهایەک لەناو کەوانەی چوارگۆشەدا هەڵدەگرێت. لووپی `for` دەتوانێت سەردانی هەر یەکێکیان بکات:

```python
fruits = ["apple", "banana", "mango"]
for fruit in fruits:
    print("I like", fruit)
```

## لووپی while: دووبارەکردنەوە تا شتێک دەگۆڕێت

لووپی `while` تا ئەو کاتەی مەرجەکەی ڕاست بێت بەردەوام دەبێت:

```python
count = 3
while count > 0:
    print(count)
    count = count - 1
print("Lift off!")
```

> وریا بە: ئەگەر مەرجەکە هەرگیز هەڵە (false) نەبێت، لووپەکە بۆ هەتاهەتایە کار دەکات. ئەگەر ئەمە ڕوویدا، بەرنامەکە ڕابگرە (لە زۆربەی دەستکاریکەرەکاندا **Ctrl + C** یان دوگمەی وەستان).

## پێکەوە بەستنی هەمووی: یارییەکی مەزەندەکردن

ئەمە سەرەتای پڕۆژەی کۆتاییتە. دێڕ بە دێڕ بیخوێنەوە و پێش جێبەجێکردنی پێشبینی بکە چی دەکات.

```python
import random

secret = random.randint(1, 20)
guess = 0

while guess != secret:
    guess = int(input("Guess a number from 1 to 20: "))
    if guess < secret:
        print("Too low.")
    elif guess > secret:
        print("Too high.")

print("You got it!")
```

بیرۆکە بۆ ئەوەی هی خۆت بێت: بژمێرە چەند مەزەندەی پێویست بوو، یاریزان بە 5 هەوڵ سنووردار بکە، یان بپرسە ئایا دەیەوێت دووبارە یاری بکات.
