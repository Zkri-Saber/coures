**گۆڕاو** (variable) ناوێکە کە بەهایەک هەڵدەگرێت تا دواتر بەکاری بهێنیت. وەک سندووقێکی ناونووسراو بیری لێ بکەرەوە.

```python
name = "Layla"
age = 15
print(name)
print(age)
```

نیشانەی `=` واتە "ئەم بەهایە لەم ناوەدا هەڵبگرە". مانای "یەکسانە" نییە وەک لە بیرکاریدا.

## گۆڕینی گۆڕاوێک

هەر کاتێک بێت دەکرێت بەهایەکی نوێ بدرێت بە گۆڕاوێک:

```python
score = 0
score = score + 10
print(score)   # shows 10
```

دێڕی دووەم لە ڕاستەوە بۆ چەپ بخوێنەوە: `score` وەربگرە، 10 ی بخەرە سەر، و ئەنجامەکە دووبارە لە `score` دا هەڵبگرە.

هەر شتێک دوای `#` بێت **لێدوان** (comment) ـە. پایتۆن پشتگوێی دەخات؛ تێبینییەکە بۆ مرۆڤ.

## جۆرەکانی بەها

| جۆر | چی هەڵدەگرێت | نموونە |
| --- | --- | --- |
| `str` (string، دەق) | دەق، هەمیشە لەناو نیشانەی وتەدا | `"hello"`، `'Baghdad'`، `"42"` |
| `int` (integer، ژمارەی تەواو) | ژمارەی تەواو | `7`، `-3`، `2026` |
| `float` | ژمارەی دەیی | `3.14`، `0.5` |
| `bool` (boolean) | ڕاست یان هەڵە | `True`، `False` |

جۆرەکە گرنگە. سەیری ئەمە بکە:

```python
print(2 + 3)       # 5
print("2" + "3")   # 23
```

کۆکردنەوەی دوو ژمارە بیرکاری دەکات. "کۆکردنەوەی" دوو دەق دەیانلکێنێت بە یەکەوە.

## یاساکانی ناونان

- پیت، ژمارە و هێڵی ژێرەوە (_) بەکاربهێنە: `high_score`، `player2`
- بە ژمارە دەست پێ مەکە: `2player` هەڵەیە
- ناوەکان جیاوازی لە نێوان پیتی گەورە و بچووکدا دەکەن: `Score` و `score` دوو گۆڕاوی جیاوازن
- ناوێک هەڵبژێرە کە خۆی ڕوونی بکاتەوە: `total_price` باشترە لە `tp`
