**بەرنامە** (program) لیستێکە لە ڕێنمایی بۆ کۆمپیوتەر. کۆمپیوتەر بە وردی جێبەجێیان دەکات، یەک لە دوای یەک، زۆر خێرا، و بەبێ ئەوەی مەزەندە بکات مەبەستت چی بووە.

ئەم بەشی کۆتاییە گرنگە. ئەگەر بە هاوڕێیەکت بڵێیت "خواردنەوەیەکم بۆ بهێنە"، خۆی وردەکارییەکان دەزانێت. بەڵام کۆمپیوتەر پێویستی بەوەیە هەموو هەنگاوێکی بۆ ڕوون بکرێتەوە.

## یەکەم بەرنامەی پایتۆنت

```python
print("Hello, world!")
```

`print` **فەنکشن** (function) ـە: فەرمانێکی ناودار کە کارێک دەکات. ئەمەیان دەق لەسەر شاشە پیشان دەدات. دەقەکە دەچێتە ناو کەوانەکان، لە نێوان دوو نیشانەی وتەدا.

دەتوانیت دەقی کوردیش پیشان بدەیت:

```python
print("سڵاو، جیهان!")
```

## لە کوێ پایتۆن جێبەجێ بکەیت

بۆ دەستپێکردن پێویست ناکات هیچ شتێک دابمەزرێنیت:

- **لە وێبگەڕەکەتدا:** دەستکاریکەرێکی پایتۆنی ئۆنلاین بکەرەوە وەک [Trinket](https://trinket.io/python3) یان [Replit](https://replit.com)، کۆدەکە دابنێ، و **Run** دابگرە.
- **لەسەر کۆمپیوتەرەکەت:** پایتۆن لە [python.org](https://www.python.org/downloads/) دابمەزرێنە، کە دەستکاریکەرێکی سادەی بە ناوی IDLE لەگەڵدایە. فایلێکی نوێ دروست بکە، بە ناوی `hello.py` پاشەکەوتی بکە، و **F5** دابگرە بۆ جێبەجێکردنی.

## بەرنامەکان لە سەرەوە بۆ خوارەوە کار دەکەن

```python
print("First")
print("Second")
print("Third")
```

دەرئەنجام:

```text
First
Second
Third
```

## کاتێک شتەکان هەڵە دەچن

ئەمە جێبەجێ بکە:

```python
print("Hello"
```

پایتۆن دەوەستێت و **پەیامێکی هەڵە** (error message) پیشان دەدات. هەڵە ئاساییە، و هەموو پرۆگرامسازێک بە درێژایی ڕۆژ دەیانبینێت. دوا دێڕی پەیامەکە بخوێنەوە: زۆرجار پێت دەڵێت چی هەڵەیە و لە کام دێڕدا. لێرەدا کەوانەیەکی داخستن ونە.

:::quiz
Q: `print("Hi")` چی دەکات؟
- [ ] "Hi" دەنێرێت بۆ پرینتەر
- [x] Hi لەسەر شاشە پیشان دەدات
- [ ] "Hi" لە فایلێکدا پاشەکەوت دەکات
Why: لە پایتۆندا، `print` دەق لە ناوچەی دەرئەنجامدا پیشان دەدات. هیچ پەیوەندییەکی بە پرینتەری کاغەزەوە نییە.

Q: پایتۆن دێڕەکانی بەرنامەیەکی سادە بە چ ڕیزێک جێبەجێ دەکات؟
- [x] لە سەرەوە بۆ خوارەوە، یەک دوای یەک
- [ ] هەموویان لە یەک کاتدا
- [ ] کورتترین دێڕ سەرەتا
Why: پایتۆن کۆدەکەت دێڕ بە دێڕ دەخوێنێتەوە و جێبەجێی دەکات، لە سەرەوە دەست پێ دەکات.
:::
