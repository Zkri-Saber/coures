نهێنیی ڕیزبەندی لە CSS دا ئەمەیە: **هەموو توخمێک سندووقێکە**. کاتێک سندووقەکان ببینیت، ڕیزبەندی زۆر ئاسانتر دەبێت.

## مۆدێلی سندووق

هەر سندووقێک چوار چینی هەیە، لە ناوەوە بۆ دەرەوە:

1. **ناوەڕۆک** (content): خودی دەقەکە یان وێنەکە
2. **بۆشایی ناوەوە** (padding): بۆشایی نێوان ناوەڕۆک و چوارچێوە
3. **چوارچێوە** (border): هێڵێک بە دەوری padding دا (دەکرێت نادیار بێت)
4. **بۆشایی دەرەوە** (margin): بۆشایی دەرەوەی چوارچێوە کە سندووقەکانی تر دوور دەخاتەوە

```css
.card {
  padding: 16px;
  border: 2px solid #333;
  margin: 24px 0;
  border-radius: 8px;   /* rounded corners */
}
```

> تاقی بکەرەوە: کلیکی ڕاست لەسەر توخمێک بکە و **Inspect** هەڵبژێرە. ئامرازەکانی گەشەپێدەری وێبگەڕەکەت ناوەڕۆک، padding، چوارچێوە و margin وەک چینی ڕەنگاوڕەنگ پیشان دەدەن.

## Block و inline

- توخمەکانی **block** (`<h1>`، `<p>`، `<div>`، `<ul>`) لە دێڕێکی نوێوە دەست پێ دەکەن و بە هەموو پانییەکە درێژ دەبنەوە.
- توخمەکانی **inline** (`<a>`، `<strong>`، `<img>`) لەناو دێڕێکی دەقدا دادەنیشن، لە تەنیشت یەکترەوە.

`<div>` توخمێکی block ـە کە مانایەکی تایبەتی نییە. بۆ کۆکردنەوەی شتەکان بەسوودە تا پێکەوە شێوەیان پێ بدەیت.

## دانانی سندووقەکان لە تەنیشت یەکتر بە flexbox

بۆ ئەوەی سندووقەکان لە یەک ڕیزدا ڕیز بکەیت، `display: flex` بدە بە باوانەکەیان:

```html
<div class="row">
  <div class="card">HTML</div>
  <div class="card">CSS</div>
  <div class="card">JavaScript</div>
</div>
```

```css
.row {
  display: flex;
  gap: 16px;               /* space between the cards */
  flex-wrap: wrap;         /* move to a new line on small screens */
}

.card {
  flex: 1;                 /* share the space equally */
  min-width: 150px;
}
```

ئەمە بەسە بۆ دروستکردنی زۆربەی ڕیزبەندییە سادەکان: ڕیزێک کارت، سەرپەڕەیەک کە لۆگۆ لە لایەک و بەستەرەکان لە لایەکی ترن، یان گەلەرییەکی وێنە.

- [x] Padding
- [ ] Margin
- [ ] Gap
Why: Padding لە ناوەوەی چوارچێوەیە. Margin لە دەرەوەیەتی، لە نێوان ئەم سندووقە و دراوسێکانیدا.

Q: دەتەوێت سێ کارت لە یەک ڕیزدا بن. `display: flex` لە کوێ دادەنێیت؟
- [ ] لەسەر هەر کارتێک
- [x] لەسەر ئەو توخمەی کارتەکانی لەخۆ گرتووە
- [ ] تەنها لەسەر `<body>`
Why: Flexbox لەسەر باوان دادەنرێت و منداڵەکانی ئەو باوانە ڕیز دەکات.
:::
