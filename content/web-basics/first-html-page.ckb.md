HTML بە **تاگ** (tag) دەنووسرێت: وشەگەلێک لەناو کەوانەی گۆشەدار کە هەر بەشێکی ناوەڕۆک ناو دەنێن. زۆربەی تاگەکان جووتن: تاگێکی کردنەوە و تاگێکی داخستن کە هێڵێکی لار (/) ی تێدایە.

```html
<h1>This is a big heading</h1>
<p>This is a paragraph.</p>
```

تاگی کردنەوە و ناوەڕۆکەکە و تاگی داخستن پێکەوە پێیان دەوترێت **توخم** (element).

## پەڕەیەکی تەواو

دەستکاریکەرێکی دەقی سادە بکەرەوە (VS Code، Notepad یان TextEdit لە دۆخی دەقی سادەدا)، ئەمەی تێدا دابنێ و بە ناوی `index.html` پاشەکەوتی بکە.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello, I'm Sam</h1>
    <p>I'm learning to build websites.</p>

    <h2>Things I like</h2>
    <ul>
      <li>Football</li>
      <li>Drawing</li>
      <li>Space</li>
    </ul>

    <p>Visit <a href="https://www.wikipedia.org">Wikipedia</a> to learn more.</p>
  </body>
</html>
```

ئێستا دوو کلیک لەسەر فایلەکە بکە. لە وێبگەڕەکەتدا دەکرێتەوە: تۆ یەکەم پەڕەی وێبی خۆت دروست کرد.

> دەتوانیت دەقە ئینگلیزییەکانی ناو نموونەکە بگۆڕیت بۆ کوردی. ئەگەر وا بکەیت، `lang="en"` بگۆڕە بۆ `lang="ckb" dir="rtl"` تا پەڕەکە لە ڕاستەوە بۆ چەپ پیشان بدرێت.

## هەر بەشێک چی دەکات

- `<head>` زانیاری *دەربارەی* پەڕەکە لەخۆ دەگرێت، وەک ئەو ناونیشانەی لەسەر تابی وێبگەڕەکە دەردەکەوێت. لەسەر خودی پەڕەکە پیشان نادرێت.
- `<body>` هەموو ئەو شتانە لەخۆ دەگرێت کە سەردانکەران دەیبینن.
- `<h1>` تا `<h6>` سەردێڕن، لە گرنگترینەوە بۆ کەمترین گرنگی. لە هەر پەڕەیەکدا تەنها یەک `<h1>` بەکاربهێنە.
- `<ul>` لیستێکی خاڵدار دروست دەکات، و هەر `<li>` ـێک یەک بڕگەیە.
- `<a href="...">` بەستەر دروست دەکات. بەشی `href` پێی دەوترێت **تایبەتمەندی** (attribute): زانیارییەکی زیادە کە لەناو تاگی کردنەوەدا دایدەنێیت.

## زیادکردنی وێنە

فایلێکی وێنە لە تەنیشت `index.html` دابنێ، پاشان ئەمە زیاد بکە:

```html
<img src="cat.jpg" alt="My grey cat sleeping on a chair">
```

`<img>` تاگی داخستنی نییە. دەقی `alt` وێنەکە بۆ ئەو کەسانە وەسف دەکات کە ناتوانن بیبینن، بۆیە هەمیشە یەکێک بنووسە.

:::quiz
Q: کام توخم دەبێت سەردێڕی سەرەکیی پەڕەکەت لەخۆ بگرێت؟
- [ ] `<head>`
- [x] `<h1>`
- [ ] `<h6>`
Why: `<h1>` گرنگترین سەردێڕە. `<head>` شتێکی ترە: بەشی زانیارییە نادیارەکەی سەرەوەی فایلەکە.

Q: لە `<a href="https://example.com">Click</a>` دا، `href` چییە؟
- [ ] تاگێک
- [x] تایبەتمەندییەک (attribute)
- [ ] تاگێکی داخستن
Why: تایبەتمەندییەکان دەچنە ناو تاگی کردنەوە و زانیاری زیاد دەکەن، لێرەدا ئەو ناونیشانەی بەستەرەکە دەیبات بۆی.

Q: بۆچی دەبێت هەموو وێنەیەک دەقی `alt` ـی هەبێت؟
- [ ] وێنەکە خێراتر بار دەکات
- [ ] ژێرنووسێک لە خوار وێنەکەوە زیاد دەکات
- [x] وێنەکە بۆ ئەو کەسانە وەسف دەکات کە ناتوانن بیبینن
Why: خوێنەرەوەکانی شاشە دەقی alt بە دەنگی بەرز دەخوێننەوە، و ئەگەر وێنەکە بار نەبێت وێبگەڕ پیشانی دەدات.
:::
