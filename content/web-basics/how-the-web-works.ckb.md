هەموو ماڵپەڕێک کە سەردانی دەکەیت کۆمەڵێک فایلە کە لەسەر کۆمپیوتەرێکی تر لە شوێنێکی تری جیهان هەڵگیراون. کاری وێبگەڕەکەت ئەوەیە ئەو فایلانە بهێنێت و بیانکات بەو پەڕەیەی دەیبینیت.

## لە ناونیشانەوە تا پەڕە

کاتێک ناونیشانێکی وەک `example.com` دەنووسیت و Enter دادەگریت، لە نزیکەی یەک چرکەدا چوار شت ڕوودەدەن:

1. **دۆزینەوەی ڕاژەکار.** وێبگەڕەکەت لە ڕاژەکارێکی DNS (دەفتەری تەلەفۆنی ئینتەرنێت) دەپرسێت ناونیشانی ژمارەیی ئەو کۆمپیوتەرە چییە کە ماڵپەڕەکەی لەسەرە.
2. **داواکردنی پەڕەکە.** وێبگەڕەکەت پەیوەندی بەو کۆمپیوتەرەوە دەکات، کە پێی دەوترێت *ڕاژەکار* (server)، و بە HTTPS داوای پەڕەکە دەکات.
3. **وەرگرتنی فایلەکان.** ڕاژەکار فایلی دەقی دەنێرێتەوە: HTML و CSS و زۆرجار JavaScript، لەگەڵ هەر وێنەیەک.
4. **کێشانی پەڕەکە.** وێبگەڕەکەت فایلەکان دەخوێنێتەوە و پەڕەکە لەسەر شاشەکەت دەکێشێت.

> تاقی بکەرەوە: کلیکی ڕاست لەسەر هەر پەڕەیەکی وێب بکە و **View page source** هەڵبژێرە. هەموو ئەوەی لەوێ دەیبینیت HTML ـە، هەمان ئەو زمانەی لە وانەی داهاتوودا دەینووسیت.

## سێ زمانەکەی وێب

| زمان | کار | وەک ئەوە وایە |
| --- | --- | --- |
| HTML | ناوەڕۆک و ڕێکخستنی: سەردێڕ، پەرەگراف، وێنە، بەستەر | دیوار و ژوورەکانی خانوویەک |
| CSS | چۆن دەردەکەوێت: ڕەنگ، فۆنت، بۆشایی، ڕیزبەندی | بۆیە و کەلوپەلی ناوماڵ |
| JavaScript | چۆن ڕەفتار دەکات: دوگمەی کارلێککەر، ناوەڕۆکی گۆڕاو | کارەبا و بۆریی ئاو |

لەم کۆرسەدا دوو زمانی یەکەم بەکاردەهێنیت. زۆرێک لە ماڵپەڕە باشەکان تەنها کەمێک JavaScript بەکاردەهێنن.

- [ ] HTML
- [x] CSS
- [ ] JavaScript
Why: CSS دیاری دەکات شتەکان چۆن دەردەکەون. HTML دیاری دەکات ناوەڕۆکەکە چییە.
