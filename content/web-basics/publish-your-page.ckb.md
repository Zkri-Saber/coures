ئێستا پەڕەکەت تەنها لەسەر کۆمپیوتەرەکەی خۆتە. GitHub Pages دەتوانێت بە خۆڕایی بیخاتە سەر ئینتەرنێت، بە ناونیشانێکی ڕاستەقینە کە دەتوانیت لەگەڵ کەسانی تردا هاوبەشی بکەیت.

## چیت پێویستە

- هەژمارێکی بەخۆڕایی لە [github.com](https://github.com)
- فایلەکانی `index.html` و `style.css` و هەر وێنەیەک، لە یەک فۆڵدەردا

## هەنگاوەکان

1. **ڕیپۆزیتۆرییەک دروست بکە.** لە GitHub، کلیک لە **New** بکە (یان لیستی **+**، پاشان **New repository**). ناوێکی وەک `about-me` ی لێ بنێ، **Public** هەڵبژێرە، و کلیک لە **Create repository** بکە.
2. **فایلەکانت باربکە.** لە پەڕەی ڕیپۆزیتۆرییە نوێیەکەدا، کلیک لە **uploading an existing file** بکە. `index.html` و `style.css` و وێنەکانت ڕابکێشە ناوی، پاشان کلیک لە **Commit changes** بکە.
3. **Pages چالاک بکە.** بڕۆ بۆ **Settings**، پاشان **Pages** لە لیستی لای تەنیشت. لە ژێر **Build and deployment** دا، **Source** بکە بە **Deploy from a branch**، لقی `main` و فۆڵدەری `/ (root)` هەڵبژێرە، و کلیک لە **Save** بکە.
4. **خولەکێک چاوەڕێ بکە، پاشان سەردانی بکە.** پەڕەکەت لە `https://YOUR-USERNAME.github.io/about-me/` دەبێت. پەڕەی ڕێکخستنەکانی Pages نوێ بکەرەوە تا بەستەرەکە ببینیت.

## گۆڕانکاریکردن

فایلێک لەسەر کۆمپیوتەرەکەت دەستکاری بکە و دووبارە باری بکەرەوە، یان لە GitHub کلیک لەسەر فایلێک بکە، پاشان ئایکۆنی قەڵەمەکە تا ڕاستەوخۆ لە وێبگەڕدا دەستکاری بکەیت. هەر جارێک commit دەکەیت، GitHub Pages لە ماوەی خولەکێک یان دوو خولەکدا ماڵپەڕەکەت دووبارە بڵاو دەکاتەوە.

> پەڕەی سەرەکیت دەبێت ناوی `index.html` بێت (هەمووی بە پیتی بچووک). ئەوە ئەو فایلەیە کە وێبگەڕەکان دەیکەنەوە کاتێک کەسێک سەردانی ناونیشانەکەت دەکات.

## پێش هاوبەشکردن

- هەموو شتێک لە ڕیپۆزیتۆرییەکی گشتیدا (public) لەلایەن هەموو کەسێکەوە دەبینرێت. زانیاریی کەسی وەک ناونیشانی ماڵ یان ژمارەی تەلەفۆنت بار مەکە.
- پەڕەکەت لەسەر مۆبایلیش وەک کۆمپیوتەر بپشکنە.

:::quiz
Q: فایلی پەڕەی سەرەکیت دەبێت ناوی چی بێت؟
- [ ] `home.html`
- [x] `index.html`
- [ ] `Index.HTML`
Why: ڕاژەکارەکانی وێب بە شێوەی بنەڕەتی بەدوای `index.html` دا دەگەڕێن، و GitHub Pages جیاوازی لە نێوان پیتی گەورە و بچووکدا دەکات، بۆیە پیتی بچووک بەکاربهێنە.

Q: لە کوێ GitHub Pages چالاک دەکەیت؟
- [ ] لە پرۆفایلی هەژمارەکەتدا
- [x] لە Settings ـی ڕیپۆزیتۆرییەکەدا، لە ژێر Pages
- [ ] بۆ هەموو ڕیپۆزیتۆرییەک خۆکارانە چالاک دەبێت
Why: Pages بۆ هەر ڕیپۆزیتۆرییەک جیا چالاک دەکرێت، لە Settings، پاشان Pages.
:::
