Your GitHub profile, at `github.com/your-username`, is a portfolio of everything you build. Teachers, universities and employers often look at it. Let's make yours look good.

## Add a profile README

GitHub has a hidden feature: if you create a repository with **exactly the same name as your username**, its README appears at the top of your profile.

1. Click **+**, then **New repository**.
2. Name it the same as your username. For example, if you are `sara-codes`, name it `sara-codes`. GitHub shows a message saying this is a special repository.
3. Make it **Public** and turn on **Add a README file**.
4. Click **Create repository**, then edit the README.

Ideas for what to write:

```markdown
# Hi, I'm Sara 👋

I'm a Grade 10 student learning web development and Python.

## What I'm working on
- An about-me website ([see it live](https://sara-codes.github.io/about-me/))
- A number-guessing game in Python

## What I'm learning next
- JavaScript
- Making games with Pygame
```

Keep it short, friendly, and about your work. Don't include your address, phone number or school schedule.

## Pin your best work

On your profile page, click **Customize your pins** and choose up to six repositories to feature. Pick finished projects you're proud of, not empty practice repositories.

## Make each project easy to understand

For every repository you pin:

- Add a one-sentence **description** (the gear icon next to *About* on the repository page).
- Write a README that explains **what it is**, **how to use it**, and includes a screenshot if it's visual.
- If it's a website on GitHub Pages, add the link in the *About* section.

## Your contribution graph

Your profile shows a grid of squares, one for each day of the year. A square turns green on days you make commits. It's a nice way to see your progress, but don't chase green squares for their own sake: one meaningful commit is worth more than ten tiny ones.

## You've finished the course

You can now create repositories, save work with commits, collaborate with branches, pull requests and issues, and use Git on your computer. Your final project puts it all together.

- [ ] `profile`

- [x] Exactly the same as your GitHub username
Why: GitHub treats a public repository named after your username as your profile README.

Q: Which repositories are best to pin on your profile?
- [ ] The ones with the most commits
- [x] Finished projects you're proud of, with clear READMEs
- [ ] Every repository you've ever made
Why: Pins are your showcase. A few complete, well-explained projects make a much better impression than many empty ones.
