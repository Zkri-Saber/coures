Every computer needs an **operating system**: the software that manages the hardware (screen, keyboard, memory, storage) and runs your apps. You probably know Windows, macOS, Android and iOS. Linux is another one, and it's everywhere, even if you've never noticed it.

## A short history

In 1991, a Finnish student named Linus Torvalds started writing an operating system as a hobby project and shared the code online for anyone to use and improve. Thousands of people joined in. Today Linux is built by developers all over the world, and it's **free and open source**: anyone can use it, read its code, change it and share it.

## Kernel and distributions

Strictly speaking, *Linux* is the **kernel**: the core of the operating system that talks to the hardware. To get a complete, usable system, the kernel is packaged with tools, a desktop and apps. Each package is called a **distribution**, or **distro**:

| Distro | Known for |
| --- | --- |
| Ubuntu | The most popular for beginners; what we use in this course |
| Linux Mint | Looks and feels a lot like Windows |
| Debian | Very stable; Ubuntu is built on it |
| Fedora | Up-to-date software |
| Raspberry Pi OS | Runs on the tiny, cheap Raspberry Pi computer |

The commands you'll learn work on almost all of them.

## Where Linux runs

- **Web servers and the cloud:** most websites you visit are served by Linux computers.
- **Phones:** Android is built on the Linux kernel.
- **Supercomputers:** since 2017, every one of the world's 500 fastest supercomputers has run Linux.
- **Everyday devices:** smart TVs, Wi-Fi routers, cars, game consoles and the Raspberry Pi.

## Why learn the command line?

Linux has desktops with windows and icons, like any other system. But its real power is the **command line** (also called the **terminal** or **shell**), where you type instructions instead of clicking.

- Servers usually have no screen or desktop at all. The command line is the only way in.
- One typed command can do what would take a hundred clicks, like renaming 500 photos.
- Programming tools, Git and cloud services all expect you to know it.

It looks old-fashioned, but professionals use it every day because it's fast and precise.
